# 摩擦算子权重、有限元模型与原生云图

## 已交付

- `trained_weights_and_history.zip`：原网格版本的 10 个实际训练检查点，含初始训练、主动补算两轮、随机补算两轮，各含 seed 17/41。每个目录包含 model.pt、逐轮日志、选择结果、训练约束、原执行源码和可直接导入 Origin 的 curve.csv。
- `native_models.zip`：十倍加密验证工况 008 的 INP、原始 FRD、元数据及求解导出记录，以及原网格候选工况 05 的 INP 和元数据。
- `training_curves.png`：Gnuplot 6.0 原生绘制的训练验证曲线；脚本为 training_curves.gnuplot。纵轴将日志中的无量纲相对误差乘以 100。
- `displacement.png`、`stress.png`：CGX 2.21 直接读取原始 FRD 绘制的有限元云图，未使用 Python 绘图。模型为局部接触试件，不能标为扎青吊桥实桥细节。
- `manifest.json` 和 `SHA256SUMS`：文件与原训练归档的校验依据。

## 版本与云图含义

已恢复的权重属于原网格（153 个物理节点）历史版本，不能称为十倍加密版本训练权重。十倍网格训练权重尚未恢复。本次未重新训练，也没有新增独立测试结果。

云图属于十倍网格的原生有限元结果（1674 节点、1214 单元），不是上述原网格网络的预测。32 个输出时刻，显示最后时刻 t=8。位移为节点位移模量，单位 mm，最大值 0.00156167；应力为外推节点应力的 von Mises 值，单位 MPa，最大值约 35.56168。应力图不是原始积分点应力图。图显示未变形几何，使用当前帧完整范围与 CGX 原生色标；图片为 CGX 原生预览分辨率。CGX 读取记录确认节点、单元和 160 个结果数据块完整。

## 目前传感器掌握的数据

在本次摩擦训练流程中，没有接入已验证的现场传感器记录，没有传感器编号、位置映射、采样率、标定信息与实测时间序列。因此目前不能报告现场位移、应变、加速度、索力、温度或风速的实测值。

已有数据为有限元仿真：节点三向位移、体积分点六分量应力，以及原始 FRD 中的接触开闭量、切向滑移、接触压力、切向接触应力。载荷和摩擦系数等为人为指定的工况输入。加密重导出的训练文件只明确填充了节点位移与体积分点应力；不能据原始 FRD 含接触量便宣称这些量全部进入了加密网络监督。

## 参数更新曲线的当前缺项

本次训练调整的是神经网络权重；主动搜索选择的是值得补算的新工况。现有日志没有记录由传感器误差驱动、针对同一结构的摩擦系数、接触刚度或材料参数逐次反演轨迹。因此 training_curves.png 只标为训练验证误差曲线，不冒充结构参数更新曲线。

结构参数更新的完整输出应包含每次迭代的参数值和单位、约束范围、测点预测与观测差、目标函数、接受或拒绝理由；实际执行反演后再用 Gnuplot/Origin 绘制参数—迭代次数及误差—迭代次数两组曲线。本交付没有伪造该项数据。

## 复现

解压两个 ZIP。用 Gnuplot 执行 training_curves.gnuplot。CGX 的注释模板为 contours.fbl；运行前剥离行尾 ` #...` 注释，以免 CGX 将其读作额外实体参数，再执行 `cgx -b contours_runtime.fbl`。所需显示环境为 OpenGL/X11。模型架构及依赖源码见仓库 automation/local_bridge_operator；每个权重包含架构尺寸、归一化与 state_dict。
