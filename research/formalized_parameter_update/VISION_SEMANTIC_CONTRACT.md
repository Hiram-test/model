# 图纸视觉语义合同

视觉模块的任务是把图纸页面编译为结构 IR。它不输出参数更新值，也不参与有限元迭代。

## 必须输出

- 梁或构件实体；
- 支承类型与坐标；
- 荷载类型、作用范围与单位；
- 截面形状和尺寸；
- 测点布置；
- 允许更新的参数类别；
- 每个关键事实在图纸中的证据框；
- `VERIFIED`、`CONFLICT` 或 `BLOCKED` 状态。

不使用置信概率。存在冲突时写入 `CONFLICT`，缺少关键事实时写入 `BLOCKED`，程序均停止。

## 运行时原则

1. 原生 DXF/DWG/BIM 属性优先于图像识别结果；
2. 视觉模型只补充结构化文件未表达的符号、关系和标注；
3. 所有数值必须带单位；
4. 支承、荷载、截面和测点均需图像位置证据；
5. 自然语言解释不进入数值核心；
6. 修改后的 IR 必须再次通过 schema 与力学前置条件检查。

## 推荐输出流程

```text
图纸原文件
  → 页面/视图定位
  → 构件、符号、尺寸、标注提取
  → 关系组装
  → JSON Schema 校验
  → 人工或规则复核
  → VERIFIED 结构 IR
  → 力学编译
```

当前示例通过 `drawing_adapter.py` 从 `examples/beam_static_drawing.svg` 编译 `COMPILED_FROM_SVG` IR。该状态只表示确定性解析完成，不表示人工图纸审核或猫道附件复现。`examples/drawing_semantics.json` 仍是手写回归夹具。扫描图、PDF 和照片可由视觉模型生成同一 IR，但参数数值仍由力学演算给出。
