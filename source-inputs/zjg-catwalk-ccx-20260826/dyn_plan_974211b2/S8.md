## 边界类句（010 是否删掉第一族）

场地：`DYN_P1_UYFREE` vs `DYN_P1_UYPIN`。

| 卡 | f1 Hz | uy_dominant | 主导跨 | 对称/位移门 | 亚 0.10 Hz |
|---|---:|---|---|---|---|
| UYFREE（正路，省略 010） | 0.06787193 | true | MAIN | 过（Umax=42.25864819934656 mm @304，\|UY\|_max=1.36e-9 mm） | 有 |
| UYPIN（指名简化，保留 010） | 0.1335403 | false | MAIN | 过（同一 42.25864819934656 mm @304） | 无 |

- 正路谱头是 **主跨横向**（`uy_dominant`，能量几乎全在 MAIN），低于 0.10 Hz。全网钉 UY 之后这根从 40 阶里消失，谱头改到 0.1335403 Hz，与历史 `migrate_DYN.dat` 前 20 阶 **逐位相同**。
- 横向张弦 15% 窗 [0.035506, 0.048037] Hz **没有** 被 f1=0.06787193 命中（相对 L1 锁力张弦 0.041772 为 +62.5%；相对 L2 合相 0.042594 为 +59.3%）。H-uy-pin 的「窗 + 振型」只完成了振型半句：第一族确实是横向主跨，但中心不是 0.0418。
- UYPIN 的 f1 频率最近名是 `L2_south_floor_n1`（0.132857，+0.51%），**振型能量却在 MAIN、面内、UZ 奇**。把 0.1335403 写成「南边跨张弦、正确第一阶」与本包 S2 能量不一致。UYPIN 40 阶里没有 0.07–0.13 Hz 的根；UYFREE 的面内反对称 0.083086 在钉 UY 后也不以同一频率出现。
- 正路不改回全网钉 UY。

## 方法句（切线 / Kg / 扰动）

主证据要的是 UYFREE 或 PIN_STATIC 命中 L1/L2 张弦且 `uy_dominant`。本包：

| 卡 | 观测 | 用法 |
|---|---|---|
| UYFREE | 主跨横向 0.06787 Hz，非零 | Kg 进入 FREQUENCY，不是机构 |
| PIN_STATIC | f1=0.06790217，uy_dominant，MAIN；步 1 U=41.95 mm @304（锁已豁免） | 换 K 之后仍是同一根横向，**不是** 0.0418 / 0.0426 |
| SLIDE_STATIC | f1=0.06789989，同样 MAIN 横向 | 滑动鞍 UX 不改这根谱头 |
| LIN_P0 | 步 1 \|U\|_max=1.589×10^10 mm @297；谱 f=0；频率 **BLOCKED** | 无 NLGEOM 则近机构。垃圾特征值不进方法门 |
| NOPERT | 父步位移仍是 P1 锁数；频率步无扰动，f1=0.095027，面内、8 根挤在 0.095–0.098 | 扰动改族；无扰动不是正路横向根 |
| IC_ONLY | 静力 cutback 发散，ccx_exit=201，频率 **BLOCKED** | 无 GRAV/二期的 IC 父步站不住 |
| MAIN_FILT | f1=0.06790214 ≥ 全桥 0.06787193；仍 MAIN 横向 | 同一 K，f1 不降；`variational_violation=false` |
| SOUTH_FILT | f1=0.1623099 ≥ 全桥；SOUTH 横向 | 主跨被抬走；不得把「SOUTH_FILT 仍 ~0.13」整行送给 H-method |
| MAT3_STEEL | f1=0.06764634（相对正路 −0.33%） | H-mass 只能微移，解释不了 0.04→0.13。静力峰改到 463 mm @1178，因为 GRAV 吃到了门架密度；这不是正路位移门 |

结论倾向：预应力切线在干活（LIN_P0 机构 vs 正路有限横向根）。正路横向根停在 0.0679，PIN_STATIC 不能把它降到张弦公式。H-not-a-clean-string 打开：面层+门架索+B31 的 X 切片不是 2302 m 铰支张弦。FILT 没有「变出」比全桥更低的根。0.0296 不在此栏。
