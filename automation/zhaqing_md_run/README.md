## 文件与复现

本结果包含本次新增/修订执行脚本、15组实际训练权重、完整每工况评测、512候选的预测和选择记录、各轮数据身份、有效参考场及审查证据。完整原生求解过程在配套native-evidence归档内。

原始有限元源代码使用固定Git提交，并按原workflow拼接pipeline与adapter；本包不修改原模型。precision_solver.py仅接受记录的原CalculiX二进制SHA，生成明确命名的打印精度变体；不能将该字节偏移补丁用于其他版本。

执行顺序：precision_solver.py → run_scenarios.py修复三个失败及对照 → continue_training.py → 独立boundary计算/审查 → evaluate_continuation.py。代码中保留运行时绝对路径；移机复现需将路径映射到新的工作目录并重新生成运行身份，不能假称改写后的manifest仍具有原SHA。

文件同步临时目录已从证据扫描中排除。损坏/缺失的原生DAT仅通过相同输入真实重放，且必须逐字节匹配原始记录SHA才能恢复；未修改原始收敛回执。历史失败记录和所有试验方案均保留，不以失败工况替换为容易的测试点。
