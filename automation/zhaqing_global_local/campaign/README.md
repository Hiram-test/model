# Durable experiment execution

The checked-in launch mode is **validation**. A source push runs implementation, conservation, full-field storage, exact checkpoint continuation, and workflow-routing assertions. It creates no native bridge history, qualified reference dataset, or new bridge-training weight. Its report is named `implementation-validation-not-bridge-training` and includes actual test logs, source hashes, observed runner resources, and the dated physical blockers in `readiness.json`.

Run it with `python automation/zhaqing_global_local/campaign/run.py validate` after installing the pinned workflow dependencies. Run `python automation/zhaqing_global_local/campaign/run.py launch` to inspect the effective route. Numerical Python is used for calculations only; scientific plots use native Gnuplot.

The current whole-bridge static equilibrium passed the independent 0.001 N free-equation force gate on 30,555 nodes. The first wind history failed the unchanged 0.02 N dynamic force gate after 13 accepted dynamic steps. Its observed roughly 17.7 seconds per step implies about 15.7 hours for 3,200 steps before static initialization and I/O, exceeding the current 15,000-second native subprocess budget. Exact native restart has not yet been qualified. The full 283-wire local reference remains incomplete after native factorization memory and contact-initialization failures. These observations do not become passes when the software tests pass.

`references` remains a separate execution mode, but `launch` rejects it while `reference_execution_qualified` is false. This qualification must be updated from actual convergence and runtime/restart evidence before the expensive native matrix is enabled. It is a numerical execution gate, not a request for user approval. Reference mode preserves raw native evidence and creates portable fields only when genuine complete-history checks pass. The global experiment retains six complete training histories, two validation histories, and two test histories, each with all 3,200 declared steps and all detailed native nodes.

`training` additionally requires a concrete prior reference workflow ID. All ten portable cases must pass the real assembly and hash checks. The continuation chain contains 75 explicit four-epoch jobs, preserving the same frozen 300-epoch experiment and exact optimizer/RNG continuation. Held-out real-bridge evaluation is gated on the actual final completed checkpoint. The full-mesh CPU benchmark estimated approximately 226.6 hours for 300 epochs, excluding actual HDF5 I/O; this is a compute estimate and contains no completed bridge-training epoch.

Global motion learning and local fatigue learning remain separate qualifications. Completing a global run does not produce local trained weights, validate an assumed aerodynamic coefficient, or establish a fatigue-life calibration. Single-wire diagnostic results cannot satisfy the 283-wire local-data gate.
