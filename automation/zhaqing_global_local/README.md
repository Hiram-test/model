# 扎青吊桥：真实构造整桥与逐根钢丝索鞍

本目录承接整桥非线性风响应和索鞍局部接触疲劳神经算子工作。当前是开发与真实计算记录，不代表两个算子已训练合格。运行状态和数值结果见 `results/zhaqing_global_local_20261026/`；原始失败结果也保留。

## 已纠正的原模型依据

- 主缆图 `03-缆索布置.dwg` 的 `16B5` 明示 **283 根 φ5 mm 钢丝**。360 根不是该图的数量。
- 原桥面板厚度50 mm取值错误：`3D10` 是连接部位水平尺寸。`762F` 给出的实际钢板厚度为 **10 mm**。
- 详细桥面采用26跨、每跨3块面板，共78块；每块6根16b槽钢，共468根。板长2690 mm、槽钢长2666 mm、横梁中心距3000 mm。以真实构件和偏心连接取代连续50 mm等效板。
- 横梁是图中420×300 mm、10 mm板组成的双腹板箱形截面，不能按单腹板工字梁处理其扭转刚度。图中400 mm腹板净高与416 mm材料表仍存在源图冲突。
- 索鞍采用原图的纵向约R1500 mm承索板、400×30 mm底板和110 mm净距双侧板。逐根钢丝实体、钢丝间及钢丝—索鞍接触都单独建模。
- 独立文件“桥跨横断面图”的项目题签不是扎青工程。它不能直接成为整桥气动力系数的来源。

可追溯数据在 `evidence/` 代码和结果目录的 `evidence/detailed_deck_source_contract.json`、`panel_stiffener_profiles.json` 中。历史冻结输入不被覆盖。

所有原生有限元自由度都保留；没有用模态投影或低阶响应多项式替代整桥求解。神经网络的积分核近似与有限元求解精度分开验证。图和曲线由原生CAD/FEM渲染器、Gmsh或Gnuplot生成，不使用Python绘图。

## 结果判定

1. 输入几何、假设、材料和原生求解文件必须有内容哈希与来源。
2. 必须先检查完整时间历程的实际平衡、拉索张力、接触状态及所需网格/时间步敏感性；失败求解不能作为监督标签。
3. 训练、验证、测试按整段独立荷载历程划分；不得把同一历程的不同窗口分到不同集合。
4. 外生风速是风响应算子的输入。有限元反馈后的实际风力单独作为审查数据，不能偷换成已知外部风速。
5. 动态增量误差和“始终保持初态”的基线必须单独报告，不能让恒载变形掩盖没学会风响应。
6. 钢丝排列、摩擦系数、初应力、连接约束和材料疲劳标定仍需明确。没有标定的寿命不发布为真实寿命。

每个运行目录的状态表示实际完成程度。`VALID_CONVERGED`仅说明所声明模型和该求解历程通过相应数值检查；它不自动升级为实际桥梁物理验证。
