# Zhaqing CalculiX screening analysis

This directory contains the compressed deterministic generator used by `.github/workflows/zhaqing-calculix.yml`.

The generated files use the common Abaqus/CalculiX keyword subset (B31, T3D2, MASS) and are intended for global screening only. Engineering release remains BLOCKED because fabrication-state cable prestress and several local interfaces are not closed by the source drawings.
