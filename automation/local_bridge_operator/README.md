# 桥梁局部模型：真实求解、图算子训练与两轮反馈

**最新补充执行结果见 [COMPLETION.md](COMPLETION.md) 和 [COMPLETION_RESULTS.json](COMPLETION_RESULTS.json)。** 已完成384项无在线全阶目标LU的平衡校正、真实扎青单向局部求解、几何非线性与摩擦接触、动力滚动训练和共享拓扑测试。工程发布仍为 HOLD，原始网络与完整有限元校正的门槛分别记录。下文保留此前624工况静力实验的历史范围与结论。

2026-10-24，本轮以 8 类明确假设的局部研究模型执行 448 个初始工况、4096 个候选搜索、32 个主动补算工况及 144 个独立校准工况；合计 624 个数据工况。每类 3 个独立种子、初始加两轮反馈，共 72 组权重。代码每一非空行均有注释。

## 实际完成的范围

实体包含钢梁、拼接试件、横撑、开孔横隔板、加劲钢梁、闭口肋桥面板、未开裂混凝土梁及叠层支座。全部使用 C3D10 二次四面体：独立四点积分刚度组装与 CalculiX 2.21 互相核对，使用同一连续表面荷载的一致节点力，逐工况检查自由节点残差、合力、合力矩和原生输出完整性。

网络采用两层异构粗化图消息传递、全局交互及仅由训练场构建的 POD 解码器，输出训练网格上的位移场。每类几何/材料/载荷参数变化，训练、验证、测试和域外几何 ID 隔离。网络保留可关闭的训练集二次多项式响应项，单列其消融结果。物理训练损失是投影平衡残差，验收另外计算完整节点平衡残差。

两轮采集均从 256 个无标签候选中，按 0.7 归一化集成分歧 + 0.3 训练覆盖距离选出 2 个新几何，真实补算后重训。测试标签不参与采集与选型。每类的单独权重、训练日志、全候选评分和原生解均已保存。

## 结论

| 局部研究模型 | 验证集选中轮 | 平均测试位移误差 | 仅多项式基线 |
|---|---:|---:|---:|
| 钢梁 | 2 | 13.07% | 14.07% |
| 全粘结拼接试件 | 2 | 3.27% | 3.18% |
| 平板杆件横撑 | 2 | 5.25% | 5.26% |
| 开孔横隔板 | 1 | 1.88% | 1.89% |
| 带加劲肋钢梁 | 2 | 10.52% | 10.63% |
| 闭口肋桥面板 | 2 | 2.24% | 1.92% |
| 未开裂混凝土梁 | 1 | 3.52% | 3.55% |
| 叠层支座 | 0 | 11.29% | 11.25% |

每类测试分母均为 8 个工况。所有原始代理均未通过完整节点平衡残差门控，发布为 HOLD。128 个测试/域外工况，分别采用神经、零位移、Galerkin 初值执行完整稀疏有限元平衡校正，384 个比较全部通过原定 1e-7 残差与 1e-5 参考场误差门槛。校正包含完整 LU 分解，不能称为神经网络独立预测或已证明总成本优势。

24 次加密计算后，各类参考几何最后两个不同细网格的位移峰值变化低于 5%。钢梁、加劲钢梁、支座的原训练粗网格峰值相对最细参考网格仍分别偏差约 31%、31%、10%；不能据此接受粗网格的工程峰值。应力峰值尚未完成网格收敛验证。

独立校准采用模型选定后另算的 72 个几何、144 个工况，名义 90% 组级区间在各类测试几何上的实际覆盖为 50%–100%。Sobol 测试设计及小样本不支持未经验证的交换性保证。域外拒绝采用登记参数域；未实现任意未知拓扑分类器。

## 模型与图纸的对应

WSDOT 6.4-A2/A3、A4、A5、A12/A14，Caltrans xs1-410-2，FHWA-HIF-22-056 闭口肋构造，以及 WSDOT 5.6-A4 预制梁/支座图提供结构与部分尺寸依据。缺失项目参数均为登记的研究假设。具体参见 `build/local-bridge-20261024/meshes/*.json`。

拼接的螺栓/板面完全粘结，没有摩擦、预紧力、间隙与滑移；横撑是平板杆件，未重建 WT 截面及节点板；混凝土模型无配筋、预应力、开裂；支座采用线弹性橡胶参数，未校准超弹性或接触；局部边界为声明的截断研究边界，未继承任何实际整桥状态。几何非线性原生探查已对 8 类执行，但没有相容的非线性物理损失，也未将其混入线性训练标签。

本实现没有完成原 MD 的任意拓扑全阶 PI-HGNO、整桥至局部边界映射、全部图纸细节复建、非线性/动力算子、项目依据的极限状态及可靠度评价。它是具有完整证据的局部静力闭环，不是整套桥梁群体系验收通过。

## 运行与复现

Python 3.12，NumPy 2.3.5、SciPy 1.17.0、PyTorch 2.5.1 CPU、Gmsh 4.14.1；绘图使用 PyVista 0.48.4、VTK 9.5.2。原生求解器使用本次冻结的 CalculiX 2.21 打印精度变体，身份见 contract.json；`CCX_EXECUTABLE` 可指向明确选择的原生可执行文件，新环境运行会产生新版本证据。

默认外部依赖目录位于仓库父目录 `local-fem-runtime`、`solver-runtime`、`render-runtime`；可用 `LOCAL_BRIDGE_RUNTIME_ROOT` 改变依赖根目录。Gmsh 必须能找到其共享库和系统 libXft/libGLU，安装时验证其真实版本。输入 MD 的历史副本哈希记录在 contract.json，原文件来自同一会话，不随源码包含。

```bash
python automation/local_bridge_operator/run.py build # 建立八类实体并执行原生与独立解核对。
python automation/local_bridge_operator/run.py initial # 计算固定几何隔离的448个初始工况。
python automation/local_bridge_operator/verify.py mesh # 求解实际加密网格并保存各级证据。
python automation/local_bridge_operator/train.py --family deck --rounds 2 --epochs 300 # 对指定类别执行三个种子和两轮主动反馈；其余类别逐一执行。
python automation/local_bridge_operator/verify.py nonlinear # 执行原生几何非线性探查，并与线性训练标签隔离。
python automation/local_bridge_operator/calibrate.py # 在所有八类模型选定后独立补算区间校准数据。
python automation/local_bridge_operator/correct.py --family deck # 对指定冻结类别测试完整有限元平衡校正及同预算零初值基线。
python automation/local_bridge_operator/render.py # 从已核验的原生FRD生成位移与应力云图。
python automation/local_bridge_operator/audit.py # 检查刚体模态、对称性、不可行输入、文件身份和逐行注释。
```

若使用交付数据包，解压到 `build/local-bridge-20261024`。数据包省略可再生 stiffness.npz 缓存，先运行 `rebuild_matrices.py`；该脚本根据保存的真实网格及材料恢复矩阵并再次核对参考解残差。数据包含所有原生输入/结果、72 组权重、预测、候选、几何、日志与修复血缘，源码由本分支管理。

`verify.py mesh` 的默认 1/0.7/0.5 网格之外，本轮对钢梁、加劲钢梁额外计算 0.35/0.25/0.18，对支座额外计算 0.35/0.25，完整记录在 mesh_convergence_final.json。原始失败及损坏文件保留以供审查，不能作为有效训练标签。
