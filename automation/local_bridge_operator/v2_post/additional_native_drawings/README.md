摩擦元数据中的 `pressure=24.3269846402` 是加载协议的基准尺度，原生输入的峰值为 31.6250800323 MPa。图中采用真实压力范围。摩擦模型是有限应变弹性钢和非线性摩擦接触，材料塑性属于另外的钢筋、热塑性模型。

热试件名义 CAD 为 100 × 30 × 20 mm、两个 R6 mm 缺口；该算例施加了不同的 x、y 缩放，因此实际缺口是缩放椭圆，不能把名义 R6 标成实际圆半径。图中轮廓由真实角点—中边点—角点的二次有限元边精确绘制。全部边界节点与原解析 CAD 的匹配已检查；圆弧端点的逆平方根恢复在输入小数舍入下病态，核验将打印精度内的切点作为原 CAD 切点处理。图中没有借用其它算例的尺寸。

热—力为单向瞬态热传导到温度相关 J2 塑性，没有塑性生热反馈或惯性。当前最终两级网格的双向全应力差为 7.701% 和 9.636%，超过固定 5% 门，参考资格仍为 `CLOSED_REFERENCE_HOLD`；没有训练热神经算子。这个结论从封闭资格 JSON 读取并显示在图纸中。

## 核验与复现

完整文件包 `v2_additional_native_drawings.zip` 包括两张 PNG、两张可编辑 SVG、精确输入文件和回执、绘图源码、来源映射以及逐文件 SHA256 清单。两个 PNG 均为 2400 × 1650，已人工检查尺寸字形、线条和标注；没有生成模拟云图或有限元响应。

解压后，在含本文件的目录执行：

```bash
python draw_additional_native_dimensions.py
```

程序只使用 Python 标准库和已安装的 `/usr/bin/inkscape`，不导入 Torch、NumPy 或 VTK，不执行原生求解器，不访问新测试响应。输入副本 SHA 必须与 `source_provenance.json` 一致，且原生输入 SHA 必须与已完成作业的回执一致；几何、集合、接触面和完整输入边界也分别核验。完整算例字段不需要装入内存。

重新渲染会将图纸回执的视觉状态写为 `PENDING_VISUAL_QA`，须实际查看 PNG 后才能将本次渲染标为通过。包内随附的 `visual_qa.json` 只认证它所引用的确切图像 SHA。数值源码的每个非空 Python 行均含真正的 COMMENT token，脚本启动时会自行验证。
