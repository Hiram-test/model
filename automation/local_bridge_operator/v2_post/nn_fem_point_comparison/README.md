# 原生位置 NN–FEM 点值比较图：测试前固定的接口

当前仅完成源码和选择规则准备，**尚未运行绘图，也未读取新测试响应**。必须等正式训练、模型冻结、测试放行、全部新参考关闭，以及最终完整字段审计和原生身份审计完成，才可以执行下面的命令。

固定选择为摩擦、钢筋两个家族各自注册顺序中的第一个 test 和第一个 OOD，即四个 `*_00` 案例；只画正式 active 分支在测试前选定的一个真实主模型，取最后一个原生输出帧。不能按结果换案例、换 seed 或换帧。选中参考失败时保留 `NOT_RENDERED` 记录，不换一个容易的案例。神经模型自身误差大或物理门 HOLD 不会阻止其真实误差图出现。

每张图有六个面板：

| 行 | 原生有限元 | 原始神经预测 | 差值 |
|---|---|---|---|
| 位移，mm | 位移向量二范数 | 位移向量二范数 | 先逐分量相减，再取向量二范数 |
| Cauchy 应力，MPa | 应力张量 Frobenius 范数 | 应力张量 Frobenius 范数 | 先相减完整张量，再取 Frobenius 范数 |

应力顺序为 `xx, yy, zz, xy, xz, yz`，平方范数权重为 `1,1,1,2,2,2`。差值图不是“两个范数的差”，也不是 von Mises 应力。标量派生在 float64 中进行，输入仍为已保存原始预测，不执行有限元校正、重推理或优化。

摩擦保留全部 153 个有效位移节点和 544 个真实应力积分点；钢筋保留全部 1,776 个有效位移节点（包括辅助插值节点）和 3,024 个真实应力积分点。坐标取原生 NPZ 的 float64 数组，并逐项验证其 float32 转换与正式预测导出坐标完全一致。重合节点不合并，不删掉支座、已知位移节点或内部积分点。

这些图是**原生位置的离散点值图，不是连续云图**。不做平滑、空间插值、节点平均、单元平均、几何重建或变形放大。所有真实点都会交给绘图器，但同一位置及三维遮挡可能使部分点在固定视图中不可见；回执记录全部提交点数和唯一坐标数。它们不将 FRD 外推到节点的应力冒充积分点应力。输入来自已独立审计的完整原生 DAT 派生字段及正式导出，不从汇总最大值、截图或少量样本反推空间场。

同一家族两张图采用相同正交相机。原生与神经预测对同一物理量共享两个固定案例的完整色标范围，差值使用单独的完整范围；不按百分位裁剪。全部值恰为零时，明确标注全零并采用 0–1 单位显示跨度，实际 min/max 仍记录为零。图中保留全历史的正式误差和物理状态；末帧图片不能替代使用全部非初始时刻、排除已知边界量后的注册主指标。

只采用实际输入控制数组中的加载路径坐标及其原始名称、原生帧号；两个模型均为准静态问题，不把这些坐标解释成含惯性的物理时间秒数。

## 授权执行条件

`pretest_source_freeze.json` 固定本源码、计划、公开契约、finalizer 和两个审计器源码 SHA。运行时首先读取并验证最终审计、测试放行和冻结模型，之后才导入 NumPy、加载已审数组或导入 Matplotlib。原生参考质量失败、原生物理回调 HOLD 或适配器错误都会记录为 `NOT_RENDERED`，不会被改成神经负样本。

仅在 root 确认最终审计完成并明确启动绘图后执行：

```bash
python render_native_nn_point_comparison.py \
  --fullfield-audit /dev/shm/bridge_complex_v2_20261025/audit/v2_final_fields_independent_audit.json \
  --native-audit /dev/shm/bridge_complex_v2_20261025/audit/v2_selected_native_identity_audit.json \
  --output-directory /dev/shm/bridge_complex_v2_20261025/post/nn_fem_point_comparison/rendered \
  --execute-after-final-audit
```

每张图使用固定的 2400 × 1600 输出。渲染只依赖既有 NumPy 2.3.5 和 Matplotlib 3.10.8 的 Agg 后端；没有 Torch、VTK、PyVista、网络、求解器或训练调用。一次只保留一个完整字段数组的末帧，先释放历史缓冲再读下一项；脚本在数据准备、探针、各图保存及最终回执前检查已发生的进程峰 RSS，监测门为 250 MiB，超门则停止，不能悄悄删减点数换取内存。这是观测峰值的拒绝门，不是操作系统预防性内存硬限制；静态源码验证不能证明未来峰值达标。

输出目录必须是本绘图源码目录下面的全新专用子目录；拒绝源码目录本身、已存在的路径和正式训练／测试输出目录，避免覆盖正式回执。

输出包括完整数组文件/成员 SHA、冻结模型身份、字段顺序、末帧真实点值 NPZ、坐标和派生量 SHA、提交点数、共享色标、相机、加载坐标、审计绑定、渲染器版本、图片及回执。回执初始为 `PENDING_VISUAL_QA`；必须实际查看图片并绑定其 SHA 后才可声明绘图通过。绘图成功不等于模型误差、有限元网格资格或工程适用性通过。
