# 完整平衡残差的在线闭环

本实验保留原始测试分母：8 类局部结构，每类 8 个测试和 8 个域外工况，共 128 个工况；每个工况比较神经初值、16 维 Galerkin 初值和零初值，共 384 项。

每类只对 4 个训练几何的刚度矩阵做一次离线 LU 分解。训练几何由确定性的最远点覆盖选取，在线预条件矩阵由输入几何与材料参数距离选择。每类另外从全部训练位移快照出发，以训练刚度作用和训练因子逆进行两轮扩充，实际重新生成 384 维粗空间，并记录其生成成本、文件哈希和全部训练来源。测试矩阵、测试位移不会进入这些离线训练步骤。

在线阶段重新组装真实 C3D10 刚度矩阵，并实际执行三个冻结神经成员的推理。对训练粗空间 `Z` 组装并分解目标的 `Zᵀ K Z`，以该粗解和训练 LU 因子组成对称两级预条件器。PCG 的三个初值使用完全相同的算子、预算和停止条件；失败时采用同一两级预条件器的右预条件 GMRES，必要时尝试另一已缓存训练因子。方法没有在线**完整目标刚度矩阵**分解，但每工况明确包含一次 **384 维粗矩阵分解**；`reduced_warm` 初值还包含一次 **16 维 Galerkin 方程求解**。不能把这两项工作简称为“在线无分解”。固定测试解仅用于最终评测，不用于停止或预条件器选择。

令 `P` 为已缓存训练刚度的逆，`Q = Z (Zᵀ K Z)⁻¹ Zᵀ`。两级预条件器为 `Q + (I − QK) P (I − KQ)`。在线目标 `K` 仅用于装配、乘法和所披露的 384 维粗矩阵；完整目标 `K` 从未传入 LU 分解。

停止检查使用原始自由节点方程，而非投影方程或预条件残差。验收要求保持为：相对平衡残差小于 `1e-7`，对固定 FEM 参考场的相对位移误差小于 `1e-5`。内部 PCG 使用 `rtol=1e-11`、每个训练因子最多 600 次迭代，每 10 次直接检查原方程残差；显式提前停止阈值为 `1e-10`。PCG 返回后若实际残差仍不低于 `1e-9`，才继续同预算 GMRES 重试：重启维度 40、最多 15 周期，最多使用两个已缓存因子。这些更严格的内部残差控制用于病态体系的误差约束；没有放宽原始验收阈值，也没有以参考场误差指导迭代。

第一轮单层预条件试验真实完成全部 384 项，其中 377 项达标，横撑和横隔板的 7 项未达标；其中一些残差已小于 `1e-7`，但位移误差仍大于 `1e-5`。记录保留于 `first_level_summary.json` 和原逐类目录。第二轮统一加入上述训练粗空间并重跑全部 128 个工况、三种初值，而非只重跑失败例或删除困难数据。

成本分别记录离线矩阵加载/训练 LU 分解、训练粗空间重新生成、神经权重恢复、在线刚度组装、384 维粗系统构建与分解、实际三成员推理、16 维降阶初值计算、所有迭代及失败重试。另列原有训练/验证数据生成时间与所有已记录神经训练轮次的时间及来源；历史网格准备、未记录的表示生成和编排开销没有伪造为零，不能据现有日志声称已测得完整历史项目总成本。每种独立方法都计入一次共享目标装配与粗系统建立；三种方法的总和不是本次实验的真实总历时。在线输入/凭据读取、自由度切片及验证/记账开销不在这些分阶段计时内，因此阶段合计不是端到端延迟。共享主机并行工作导致计时有噪声，不据此宣称稳定吞吐优势。

这是有限元迭代校正闭环。达到残差阈值的结果包含真实数值迭代，不能归为神经网络单独预测已经满足力学方程，也不证明其优于零初值或传统降阶初值。原局部模型的粗网格精度、接触/材料本构、项目边界等限制继续适用，不据此发布工程安全结论。

```bash
python automation/local_bridge_operator/residual_online.py # 可选复现实验第一轮，保留真实失败而不覆盖两级结果。
python automation/local_bridge_operator/residual_online_summary.py # 汇总第一轮并写入 first_level_summary.json，保留所有失败。
python automation/local_bridge_operator/residual_online_v2.py # 完成八类、128个冻结工况、384项同预算两级预条件对照。
python automation/local_bridge_operator/residual_online_summary_v2.py # 独立重读所有保存位移与原始刚度，复核门槛、训练隔离与全部成本。
```

第二轮逐类结果位于 `build/residual-online-20261024/two_level/<family>/evaluation.json`，离线参考身份与训练粗空间来源分别位于同目录 `offline.json`、`coarse_training_sources.json`。每个工况的原始/降阶/校正/参考位移保存在相应 NPZ，最终结果集中于 `build/residual-online-20261024/summary.json`，同时保留于 `two_level/summary.json`。第一轮逐类目录继续原样保留。`girder_pilot_without_inference_timing` 是保留的先导诊断，未进入最终任何分母或时间对比。
