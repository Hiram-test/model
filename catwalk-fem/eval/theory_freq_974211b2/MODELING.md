## 0. 这层要回答什么

CCX 一阶大约是附件首对的 4.5 倍，不是再调一次全桥网格能看清的事。先把同一套已锁的 `L, T, μ` 压成几层能手算的理论模型，看哪一层落在 0.03 附近、哪一层落在 0.1335 附近，从而判断频率差是锁力错了，还是模型类本身就不是同一个根。

974211b2 自己的拓扑：Y≈0 单线二维等效，全部节点 `UY=0`，面层 TENSTR + 门架索 TENSTR + 71 榀 B31。21 个横向通道是节点标记，不是两幅之间的弹簧。MAT3 密度 ~0，门架质量不在 CCX 惯性里。

## 2. 第 1 层：最简化两索

假设：只看主跨；一端到一端铰支；一条等效面层线，或两条完全相同、互不耦合的平行线（B=42.90 m，图纸间距；MCT 里没有第二幅）。

公式：

- 张弦 `f_n = n/(2L) √(T/μ)`
- 垂度（T 与自重一致时）`f_n = n √(g/32d)`
- 两条平行、k=0：同一根，二重根，不能裂成 0.0296/0.0301
- 面内 Irvine：`tan(Ω/2) = Ω/2 − 4/λ² (Ω/2)³`，`Ω = ωL/√(H/μ)`；反对称 `f = 2n f_taut`

数值（g=9.806）：

| 根 | Hz | vs 0.0296 | vs 0.1335403 |
|---|---:|---:|---:|
| 垂度 n=1 | 0.036717 | +24.0% | −72.5% |
| 锁力张弦 n=1 | 0.041772 | +41.1% | −68.7% |
| 两平行索（未耦） | 0.041772 / 0.041772 | 同上 | 同上 |
| Irvine 反对称 1（锁力） | 0.083544 | +182% | −37.4% |
| Irvine 对称 1（锁力，λ²=148.5） | 0.113821 | +285% | −14.8% |
| 锁力张弦 n=3 | 0.125315 | | −6.2% |

自判：这一层的**基频**在 0.037–0.042，和附件首对是同一量级，还高 24–41%。它不是 0.1335。对不上 0.1335 不停，不改主。

## 3. 第 2 层：双元 MCT（面层 + 门架索）

假设：同一竖平面里两条连续索，71/41 道门架当轴向连杆，h=8.0 m（叠表跨中面层 113.3、门架索 121.3）。合相刚接退回一根等效索 `T_Σ, μ_Σ`。面层相对门架索的光学支用 `k=EA/h` 的 41 个点弹簧。

`T_Σ = 13625.32 kN`，`μ_Σ = 354.300 kg/m`，`c_Σ = 196.10 m/s`。

锁力下门架索波速比 `β = (T_p/μ_p)/(T_f/μ_f) = 1.195`（大于 1）。老理论要慢扭转，靠的是 β<1；锁力状态正好相反。

南边跨是斜跨（340.6 → 126.75），叠表所谓 sag 106.9 m 是端高差，不是跨中下垂。这一跨的第一公式是张弦，不是 `√(g/32d)`。

自判：主跨合相基频还在 0.043，仍靠近附件量级，不是 CCX。**真正贴上 0.1335403 的是南边跨张弦 n=1。** 门架光学支在 kHz，解释不了 0.13。对不上主跨基频出现在 CCX 谱头，不停。

## 4. 第 3 层：双元 MCT + 横向通道

974211b2 **实现不了这一层**：没有第二幅，UY 钉死，21 个通道节点不是两幅弹簧。

理论重建：两幅相同的双元线，B=42.90 m；主跨 13 道通道站位用图纸尺寸链；质量两本账 5769.2 / 10130 kg，不叠加。

同相：通道只加质量。差动：通道加刚度，中线质量不进系统滚转惯量。

单幅慢扭转（老 M5 半径：`r_f²=3.4525`，`r_g²=69.15`）：

`C_θ = T_f r_f² + T_p r_g²`，`J_θ = μ_f r_f² + μ_p r_g² + J_frame`

`J_frame = 822.38 kg·m` 来自图纸门架匀化。CCX 没有这项质量。

| 根 | Hz | vs 0.0296 | vs 0.1335403 |
|---|---:|---:|---:|
| 两幅同相 n=1（13×10130 kg） | 0.040788 | +37.8% | −69.5% |
| 锁力扭转 n=1 | 0.042237 | +42.7% | −68.4% |
| **垂度力扭转 n=1** | **0.034315** | **+15.9%** | −74.3% |
| β=0.6（锁力面层波速、把门架索 C 砍掉） | 0.031941 | +7.9% | |
| 硬管差动 n=1 | 2.45 | 出带 | 出带 |

要把锁力扭转放到 0.0296，需要 `c_T = 136.28 m/s`，也就是 `J_θ` 从 6793 加到 13831（约 2.04 倍），或者把高位索的 C 再砍一截。13×10130 kg 的质量分裂已经约 4%，比附件首对 1.67% 还宽；再加正弹簧只会更宽。反推那个 1.67% 会得到负刚度，不当物理通道。

自判：这一层的**拓扑**才是附件首对（近双根 / 慢扭转）能出现的地方。用 **974211b2 锁力**算出来的绝对频率仍在 0.04，没有落到 0.0296。最靠近 0.0296 的数字是“垂度力 + 高位惯量”那一支（0.0343），那是老理论的 H，不是这张主的 INIFORCE。不把老理论的 0.0297 回填成锁力。对不上不停。

## 5. 第 4 层（改良）：四跨张弦目录对 CCX 20 阶

主跨不是这座二维模型里唯一的跨。北边跨 L=648.112、南边跨 725.276、南辅跨 496.908，锁力都在 1.0–1.1×10⁴ kN。短跨张弦基频本来就在 0.13–0.19。

`migrate_DYN.dat` 对上最近孤立跨根（只报头几阶；后面谱密，逐阶对号不当证明）：

| CCX | Hz | 最近孤立根 | 理论 Hz | rel |
|---|---:|---|---:|---:|
| 1 | 0.1335403 | 南边跨面层张弦 n=1 | 0.132857 | −0.51% |
| 2 | 0.1572925 | 北边跨合相张弦 n=1 | 0.154968 | −1.48% |
| 3 | 0.2151652 | 主跨合相 n=5 | 0.212972 | −1.0% |

主跨张弦 n=1（0.0418）和 n=2（0.0835）不在这 20 阶的谱头。鞍座是 UZ 固定、UX 可滑，四跨轴力是通的；这一层还没有解滑动鞍的连续条件。T3D2 胀成 C3D8I 之后，参与系数只能软读：一阶 EMM_Z≈0、RY 很大，和“偶数面内 / 短跨投影”都能圆，不当第二套频率。

自判：CCX `f1` 贴的是短跨面内张弦，不是主跨一阶，更不是附件首对。主跨低频为什么没排到谱头，这一层没关掉。不当门停。

## 6. 总判

| 问 | 答 |
|---|---|
| 哪一层贴近附件 0.0296/0.0301？ | 第 1 层垂度基频（0.0367，+24%）和第 3 层垂度力扭转（0.0343，+16%）在同一量级。第 3 层才有近双根的拓扑。锁力本身到不了 0.0296。 |
| 哪一层贴近 CCX 0.1335？ | 第 2 / 4 层的**南边跨张弦 n=1**（0.13286，−0.51%）。 |
| 差从哪来？ | 不是把主跨锁力再乘一次。二维 Y 钉死的双元线根本没有两幅慢扭转 / 通道近双根；它能先报出来的最低根，落在短跨面内张弦（~0.13）。附件首对是另一类根。 |
| 和主跨张弦比？ | 0.13354 / 0.04177 ≈ **3.20**。和附件首对比 0.13354 / 0.0296 ≈ **4.51**。口语里的“约高一倍”不锁成数。`0.06438` 不是 CCX。 |
| 符合附件 2-3？ | 不写。 |

还开着的：滑动鞍四跨连续、T3D2 胀实后的参与系数、锁力 β>1 时慢扭转要怎样的额外 J。这些够后面做计算，不够宣布对上。
