# 张靖皋猫道 ANSYS 干净动力输入包

本目录交付一套可审计的 Mechanical APDL 输入链，不包含任何伪造或预先宣称通过的计算结果。输入源固定在 `Hiram-test/model` 的 `f99-chain-closure` 分支提交 `2c7e7cd64467a0e61801c0091c407a9b0edbdef2`。该分支保留了 S10—C20—D10—E10—E20 的完整执行谱系，本包只从其中的 S10 冻结源重新装配，不恢复 Release 中的 700 MB `.db`。

## 1. 这套输入解决什么

本包把原来混在同一 S10 作业中的四类内容拆开：

**物理模型装配 → 非线性静力平衡 → 平衡态线性摄动模态 / 零新增荷载全瞬态 / 有限振幅扭转释放**

物理装配入口不读取 `apply_modal_roty_stabilization_xlong.inp`。上层作业只有在参数 `CW_USE_ROTY_GAUGE=1` 时，才显式加入 2860 个横梁 `ROTY` 基准约束。因此，“物理约束”和“为消除梁轴向自旋零空间设置的数值基准”不再混为一体。

`apply_authoritative_mct_gravity_v1.inp` 也不进入物理装配入口。重力由每个求解入口使用 `ACEL,0,0,9806` 明确施加，避免装配文件改变求解处理器状态。

## 2. 文件及用途

| 文件 | 用途 | 是否求解 |
|---|---|---:|
| `solver/00_assemble_physical_model.inp` | 读取冻结 S10 源并建立统一物理模型 | 否 |
| `solver/01_model_gate.inp` | 核对节点、单元族、支承和 ROTY 约束数量 | 否 |
| `solver/02_define_probe_nodes.inp` | 确定十个主跨双幅索系探针节点 | 否 |
| `solver/10_static_equilibrium.inp` | 非线性恒载平衡、零增量保持、质量与反力闭合 | 是 |
| `solver/20_prestressed_modal.inp` | 重新建立同一静力基态后提取 80 阶线性摄动模态 | 是 |
| `solver/30_zero_load_transient.inp` | 同作业预加载后打开时间积分，检查零荷载漂移 | 是 |
| `solver/40_ta1_twist_release.inp` | 施加相对平衡态的 TA1 型反对称扭转位移并释放 | 是 |
| `solver/50_buffeting_not_armed.inp` | 抖振功能硬锁，防止动力基态未通过时直接加载 | 否 |

这里“是否求解”描述输入文件被执行后的行为。本交付过程没有启动 ANSYS，因此目前没有数值通过结论。

## 3. 强制运行合同

Mechanical APDL 的工作目录必须设置为本目录下的 `solver`。四个求解入口通过相对路径读取：

`../../../ultra_runs/S10_SECTION_SHEAR_20260716T050342389124Z/solver`

若改变仓库目录结构，必须同步修改 `00_assemble_physical_model.inp` 中的全部 `/INPUT` 路径，并重新生成哈希清单。

每次只能运行一个顶层入口，不能把 `10`、`20`、`30`、`40` 串在同一个已有会话里。每个入口均以 `/CLEAR,START` 开始，并设置独立 jobname。

## 4. 推荐执行顺序

第一步执行 `10_static_equilibrium.inp`。默认 `CW_USE_ROTY_GAUGE=0`，先检查纯物理模型能否完成非线性静力和零增量保持。其最低门禁为：

- 109086 个节点；
- 172994 个单元；
- 73692 个 TYPE4；
- 48620 个 TYPE6；
- 17679 个 TYPE70；
- 33003 个 TYPE71；
- 464 个 UZ 支承节点；
- 总质量与 4108.46690758 tonne 的绝对误差不超过 \(10^{-6}\) tonne；
- 竖向反力相对闭合误差不超过 \(10^{-4}\)。

若严格模式出现由横梁轴向自旋导致的奇异性，只将入口顶部的 `CW_USE_ROTY_GAUGE=0` 改为 `1`，重新建立一个独立作业。不能在旧数据库上补约束继续算。诊断模式必须出现恰好 2860 个 ROTY 基准约束。严格模式与诊断模式的索力、反力、实体位移和目标模态应另做敏感性比较；“加约束后能收敛”本身不是物理正确性的证明。

第二步执行 `20_prestressed_modal.inp`。该入口重新完成两步静力基态，然后从载荷步 2 最后子步进行 `PERTURB,MODAL`。输出包括完整 RSTP、原生 `SET,LIST` 和 80 阶频率 CSV。不得按频率最近原则把总序 M1—M14直接命名为附件的 LS、VA、LA、TA、VS、TS。

第三步执行 `30_zero_load_transient.inp`。该入口在同一个 full-transient 作业内先关闭时间积分，完成恒载平衡和两个相同的零增量保持步，再打开时间积分。动力阶段不增加任何节点力、风荷载或位移激励。输出的 `cw_clean_zlt_probe_drift.csv` 记录十个探针从动力打开前到末时刻的 UZ 漂移。若这一阶段不能稳定保持，禁止进入自由释放和抖振。

第四步执行 `40_ta1_twist_release.inp`。该入口先读取探针的实际平衡位移，再叠加反对称扭转位移，因此不会把绝对 UZ 误当成增量 UZ。默认峰值为 10 mm。建议在独立工作目录中分别设置 1、5、10、20、50 mm，建立频率—振幅骨架关系。该输入只产生 TA1 型宽带扭转释放，不等同于严格非线性正常模态；后处理仍需使用多测点相位、对称性和时频识别确认响应分支。

## 5. 关键参数

四个求解入口顶部均保留少量可编辑参数。任何修改都应创建新 jobname 和新目录，不能覆盖前一次结果。

- `CW_USE_ROTY_GAUGE`：0 为纯物理装配，1 为显式零空间约束诊断；
- `CW_NMODES`：摄动模态提取阶数，默认 80；
- `CW_HOLD_TIME`：零荷载瞬态保持时长，默认 60 s；
- `CW_RELEASE_TIME`：扭转释放响应时长，默认 120 s；
- `CW_DT`：固定瞬态时间步，默认 0.05 s；
- `CW_TWIST_AMP_MM`：单幅竖向扭转位移峰值，默认 10 mm；
- `CW_OUT_EVERY`：瞬态结果保存间隔，默认每 10 个子步。

这些是诊断输入的初始设置，不是规范阈值。时间步和记录长度必须在实际运行后继续做收敛性检查。

## 6. 不能从本包得出的结论

在 ANSYS 未真实执行、结果门禁未关闭前，不得声称：

- 新模型已经复现附件 TA1 = 0.0996 Hz；
- 0.073 Hz 与 0.0996 Hz 的差异已经由几何非线性解释；
- 现有 S10 DB 已被证明错误；
- TA1 型位移释放已经得到严格非线性模态；
- 抖振模型可以直接加载；
- `CW_USE_ROTY_GAUGE=1` 是真实物理约束。

`50_buffeting_not_armed.inp` 会主动退出。只有静力、摄动模态、零荷载瞬态和有限振幅释放全部形成可追溯结果后，才应新建抖振载荷入口。
