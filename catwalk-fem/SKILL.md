# 任务

把 Release 中的猫道中心线 STEP 转成可审计 CalculiX `.inp`。STEP 只提供坐标。
材料、截面、质量、预应力、边界和工况必须与坐标系自洽，且不得从 S10 `.db`、
B00、MCT 或附件频率回写。

# 硬约束

1. \(x=\text{桩号}-K16+876.000\)，单位米，北→南为正。
2. 禁止用 `X - xmin` 去对站。变换必须由塔柱高点/鞍点证据决定。
3. 材料与索力只允许来自图纸、CALC-INPUT、标准和已登记假定。
4. TARGET-FREQ / TARGET-SHAPE 与求解器隔离。
5. 两幅猫道独立自由度，禁止镜像约束。
6. 边界 NSET 与荷载作用域必须引用同一批节点坐标。
7. 没有真实 `.inp` 不得写成已过门。

# 工作顺序

1. 冻结章程与源清单。
2. 解析 STEP，审计单位、跨径、Y 间距、垂度、塔柱 X。
3. 坐标过门。
4. 分类、粗化、独立赋性、解析找形。
5. 写完整 `.inp` 与工况合力账。
6. 跑预求解门。对冻结哈希 `82548e6a`：ccx 2.21 已在副本上跑过，
   `*INITIAL CONDITIONS` 为 ELSET+单轴，读入失败（exit 201）。
   不改该哈希，不把词法失败写成已求解。
7. 写论文。
