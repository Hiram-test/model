## 使用注意

1. **平稳谱方法的适用边界**：龙卷、下击暴流、derecho、皮特拉克为非平稳/小尺度事件，
   Kaimal+Davenport 平稳抖振框架只能给**量级参考**；工况表中这些行的 U10 为名义换算值
   （标 \*），结论只允许写"包络参考"，不允许写"复现该事件"。
2. **换算链**：所有非 10-min 口径原始值按表头约定换算；每行 JSON `note_cn` 记录原始口径。
3. **桥址映射**：扫掠时统一用对数律 `U(z)=U10·ln(z/z0)/ln(10/z0)`，z0=0.003 m（开阔水面），
   猫道高程取 z=60 m（跨中量级）；湍流度按类别取 `Iu` 列，Kaimal 谱 + 指数相干。
4. **主锚点**：`site_sutong_100yr_obs`（38.9 m/s，同河段实测外延）是与附件 2-3 对照的
   设计风档位；全球工况都以它为 1.0 归一化参考。
5. C 级行在正式报告中必须保留"未在线复核"标注，或在执行前补核。
