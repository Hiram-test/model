## 第二节 极端工况与图谱构建（含新方法）

### 2.1 全球极端风工况库

- 【目的】收全世界极端风并统一口径，作为图谱的事件层。
- 【输入】`artifacts/extreme_weather_library.{json,md}`（43 项，A/B/C 置信，
  换算链 1-min÷1.14 / 2-min÷1.06 / 3-min÷1.05 / 3s÷1.42）。
- 【产出】分类总表 + 口径换算说明 + C 级复核清单。
- 【Grok 填写指令】15 项 C 级先复核再用；复核不过就保留角标出图。

### 2.2 图谱构建新方法：主曲线连续图谱（本方案的方法学贡献）

- 【目的】把"43 个工况逐个跑"的离散表，升级为**风特征空间上的连续响应曲面**，
  并让预警系统能 O(1) 查询。
- 【方法要点】（三层图谱 + 两个无量纲数 + 一次性主曲线）
  1. **无量纲化**：对每阶模态 k 定义折减频率 ñ_k = n_k L_u / U 与
     相干数 χ_k = C n_k L_ref / U。谱峰响应可分解为背景项+共振项
     （Davenport 分解），共振项 σ²_R,k ∝ (ρU·CdD)²·σ_u²·Ĵ(ñ_k, χ_k)·(π n_k / 4ζ_k)/[(2πn_k)²m]²，
     其中联合接受函数 Ĵ 只依赖 (ñ, χ)——**对给定模态基只需算一次**，
     存成主曲线族 Ĵ_k(χ)。
  2. **连续层**：任意 (U, I_u) 的四通道响应 = 主曲线插值 + ζ_aero(U) 修正，
     单次查询毫秒级；43 个named事件退化为曲面上的**投影点**（事件层）。
  3. **边界层**：曲面上叠三条等值线——施工限值线、设计值线、
     生存边界线（索利用率=1，破断力〔待填:图纸〕），加平稳性适用域
     （龙卷/下击暴流域外挂静阵风推覆界，A3 逻辑）。
  4. **不确定度带**：CdD 区间 × Iu 类别 × C 级工况置信 → 曲面每点带
     [P16, P84] 区间；带宽本身入图。
  5. **版本化（活图谱）**：v0 占位气动 → v1 附件校准 → v2 实测贝叶斯更新
     （见 3.4），图谱文件头记版本与参数指纹。
- 【输入】`artifacts/modal_basis.npz`；引擎 `code/buffeting.py`（逐点真值校核用）。
- 【产出】新脚本 `code/master_surface.py`〔Grok 写，接口：输入 modal_basis +
  config，输出 `artifacts/atlas/master_surface.npz`（(U,Iu) 网格 × 4 通道 ×
  [P16,P50,P84]）+ 与逐工况直算的交叉验证表（误差 <5% 为 PASS）〕。
- 【Grok 填写指令】主曲线法与逐工况直算在 43 事件点上全量交叉验证并给
  误差直方图；不过 5% 门就修方法，不许静默放宽。

## 第三节 系统预警架构（图谱之后系统怎么判别）

### 3.1 输入层与状态判别逻辑

- 【目的】回答"有了图谱，系统怎么判别"。
- 【方法要点】三路判别，10 分钟滑动窗：
  1. **风侧（前馈）**：桥址风速仪 → (U, I_u, 阵风因子 GF, 谱形)；
     先做**平稳性判别**：GF>〔待填:2.0〕或谱形偏离 Kaimal 检验失败 →
     切"非平稳模式"查 A3 静阵风包络；否则查 A5 连续图谱得四通道
     预测带 [P16,P84]。
  2. **响应侧（反馈）**：加速度计 RMS（带通 0.02–1 Hz，10-min）与预测带比对：
     带内 → 正常；**超带** → 异常旗（结构状态改变或模型漂移），
     加密采样 + 人工复核，不直接升级风预警。
  3. **预报侧（提前量）**：台风路径/数值预报 72 h → 未来 U 档位在图谱上
     预演，输出"预计 T+xx h 达到黄/橙"。
- 【输入】传感最小集〔待填:跨中+塔顶风速仪各 1、两幅跨中/四分点加速度计
  4–6 只、GNSS 1（可选）〕；图谱 `master_surface.npz`。
- 【产出】判别状态机图 + 伪代码（下）+ 传感布设表。

```text
every 10 min:
  U, Iu, GF <- anemometers (高度修正到 z_deck)
  mode <- NONSTATIONARY if GF > G_thr or spec_test fail else STATIONARY
  band <- Atlas.A5(U, Iu)         # 四通道 [P16,P84]（或 A3 包络）
  L_wind <- level(band vs {蓝,黄,橙,红}阈值)
  sigma_meas <- accel RMS
  anomaly <- sigma_meas outside band   # 只触发复核，不直接升级
  L_fcst <- forecast_replay(track_72h)
  LEVEL <- max(L_wind, L_fcst);  dispatch(actions[LEVEL]);  log -> 3.4 回路
```

### 3.2 阈值体系与分级动作

- 【目的】把图谱边界线变成可执行的四级预警。
- 【方法要点】
  | 级 | 触发（任一） | 动作 |
  |---|---|---|
  | 蓝 | U 达施工作业限值〔待填:规范猫道上人停工风速〕 | 限制作业/系挂 |
  | 黄 | 预测带 P84 ≥ 50% 设计响应〔待填:附件2-3设计RMS或位移限值〕 | 停工、清空猫道 |
  | 橙 | ≥80% 设计响应 或 索利用率 ≥〔待填:0.5/系数依破断力〕 | 人员全撤、锁定通道、监测加密至 1-min |
  | 红 | 触生存边界（利用率→1 或超平稳适用域的实测非平稳强事件） | 结构应急预案、禁入、事后检查清单 |
- 【Grok 填写指令】阈值数字全部从规范/附件/图纸回填并注出处；
  填不上的保留〔待填〕并在正文声明"阈值未定版不可上线"。

### 3.3 预警时间线与运行流程

- 【目的】把 3.1/3.2 排成可运营的时间线。
- 【方法要点】72 h 路径预演 → 24 h 施工窗口调度 → 1–6 h 临近升级 →
  10-min 实时判别 → 事件中 1-min 加密 → 事后 24 h 复核回填。
  张靖皋猫道 2026-09 开始架设（公开报道），预警系统上线窗口与此对齐。
- 【产出】泳道图（气象输入/图谱服务/结构监测/施工调度四条泳道）。

### 3.4 活图谱回路（模型—实测闭环）

- 【目的】让图谱随实测进化，而不是一次性交付。
- 【方法要点】每次风事件后：实测 (U,Iu,σ_meas) 三元组入库 →
  贝叶斯更新气动参数后验（CdD、Cl′；先验=附件风洞值）→
  重生成 master_surface → 图谱版本 +1，阈值线联动重算；
  连续 N 次超带且更新后仍超 → 转结构核查（可能损伤/边界条件变化），
  这一步是**预警系统与健康监测的交接面**。
- 【产出】更新协议 + 版本日志格式 + 交接判据〔待填:N、带宽阈值〕。
