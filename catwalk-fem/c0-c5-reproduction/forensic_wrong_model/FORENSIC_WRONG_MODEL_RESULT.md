# 已作废：五个争议频率的目标条件化拟合

**状态：INVALIDATED / 不得作为取证结论引用。**

上一版在已知附件五个目标频率后反求两个刚度系数，并据目标方向选择质量重复与模态重标解释。即使数值误差很小，这种做法仍属于目标条件化拟合，不能证明任何工程人员实际采用过相同的 APDL 建模路径，也不能作为错误机制的因果证据。

其中以下内容全部撤回：

- 以 0.45% 最大频率误差作为机制成立依据；
- 将 5.61 m、9.07 m 等反求尺度解释为实际高位主节点高度；
- 在没有独立质量台账证据时，把 SIDE3、VS2 归因于横向通道 MASS21 full/half 重复；
- 为降低误差而事后改选 TS2、VS2 分支。

原脚本、CSV 和 JSON 仅保留为方法错误的审计记录，不进入后续结论链。

后续采用不读取附件目标频率的正向方法：先根据工程人员最可能的建模操作构造离散 APDL 错误变体，再计算完整频谱、用 MAC 和模态族指标追踪分支，最后才解盲比较。新的因果假设与试验设计见 `HUMAN_WORKFLOW_RECONSTRUCTION.md`。
