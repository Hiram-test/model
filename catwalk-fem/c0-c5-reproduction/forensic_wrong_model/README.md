# 五个争议频率的双路线取证框架

本目录同时保留两条互补路线，不互相覆盖。

## Track A：低维数值可达性

入口：`FORENSIC_WRONG_MODEL_RESULT.md`

从 C3 物理基线与附件五个目标频率出发，反求少数共享矩阵扰动方向，判断哪些错误类型在数学上有能力同时造成 TA1、TS1、TS2、SIDE3、VS2 的差异。

该路线用于：

- 可达域判断；
- 灵敏度排序；
- 候选错误量级估算；
- 正向试验设计。

该路线是目标条件化逆问题，不单独承担因果证明。

## Track B：人类建模工作流因果重构

入口：`HUMAN_WORKFLOW_RECONSTRUCTION.md`

从工程人员建立 LINK–BEAM–MASS21 大模型时的实际操作出发，优先检验为连接和消除奇异而批量使用 `CERIG/CP/CE`、固定或间接消去滚转自由度的可能性。错误变体在生成阶段不得读取附件目标频率，必须正向计算完整频谱后解盲比较。

该路线用于：

- 解释一次具体建模决策如何形成系统误差；
- 区分一级 T 族异常与二级谱序重排；
- 构造 E1–E4 离散 APDL 错误变体；
- 形成最终因果证据。

## 联合使用顺序

1. Track B 根据人类工作流提出离散错误操作；
2. Track A 判断该操作对应的矩阵扰动是否进入五项差异的可达方向；
3. 在不知道附件目标值的条件下生成并求解 E1–E4；
4. 用 MAC、左右幅相关性、滚转参与率、奇偶性和跨别能量冻结分支；
5. 最后加载附件表 4-1 解盲比较；
6. 只有同时满足频谱、振型和谱序，才提升为高可信错误机制。

两条路线均保留：Track A 回答“什么错误有能力产生这些数”，Track B 回答“工程人员最可能怎样产生这种错误”。
