\begin{abstract}
This paper records a complete, auditable agentic finite-element modelling run
for the Zhangjinggao construction catwalk. A 77\,MB millimetre centre-line STEP
is parsed, mapped into the project convention
\(x=\mathrm{chainage}-K16+876.000\), classified against drawing topology,
coarsened, and written as a CalculiX deck. Floor-rope and portal-rope anchors
are separate \texttt{*NSET}/\texttt{*BOUNDARY} families. Twenty-one
cross-passages and 142 portal frames (71 stations per deck; Chinese classifier
U+6980, not the look-alike U+69EC) reconcile against the drawing station lists
with zero insertions. The frozen main deck
\texttt{catwalk-fem/artifacts/zjg\_catwalk\_coarsened.inp} has SHA-256
\texttt{82548e6a3bd2612b6b39a08c313402b32a1961af6eba018158267906276ab6da}
and is not rewritten. CalculiX 2.21 was executed on a byte-identical copy.
Reading \texttt{*INITIAL CONDITIONS, TYPE=STRESS} failed on the first data row
\texttt{E\_FLOOR\_ROPE,3.549611E+08} with exit code 201. No \texttt{.frd} was
written; the \texttt{.dat} is empty; \texttt{.sta} and \texttt{.cvg} contain
headers only; wall-clock time was \(0.74\)--\(0.82\)\,s; no assembled equation
count was issued. The card is ELSET name plus one uniaxial stress. CalculiX
2.21 \S7.76 requires element number, integration point, and six global stress
components. Twenty-six coordinate/topology gates PASS. Frequency targets remain
isolated. This paper therefore certifies a hashed, coordinate-gated,
topology-reconciled deck and a documented solver-parse failure---not a solved
spectrum and not a fourteen-mode match.
\end{abstract}

\section{Introduction}
\label{sec:intro}

\paragraph{Related work.}
Automated CAD-to-FEM pipelines exist for buildings and bridges, but they
usually inherit an already-consistent coordinate system and a single support
family. Construction catwalks of a multi-span suspension bridge break that
assumption: two walkways, two rope families with different physical anchor
stations, discrete portal frames, and discrete cross-passages, all written in
highway chainage. A companion theory archive
(\texttt{catwalk-theory/thirteen-mode-models}, v1.2) already freezes the
drawing topology and the isolation protocol for fourteen low-order families.
That archive is a theoretical model family, not a CalculiX deck.

\paragraph{Method.}
The run follows \texttt{catwalk-fem/SKILL.md} and \texttt{PLAN.md}. Geometry is
STEP-only. Materials, sag, and loads come from drawings and the check report.
The coordinate gate is a hard stop: identity unless saddle-height evidence
requires a shift, and never \(X-x_{\min}\). Topology is reconciled against
frozen drawing lists: 21 passages and \(71\times 2=142\) portal frames.
Anchors are two families, not one mixed set. The writer emits a complete
keyword deck. After the hash is frozen, CalculiX may be run only on a copy.

\paragraph{Experiment.}
Release \texttt{catwalk-attachment23-v2.0-s10-20260716} file
\texttt{cw\_S10\_0716t050342\_a4\_centerline.step} (SHA-256
\texttt{d03d01e38b823df5af4c1ff9b0b175fdfb87b097b9cda9a03af5d14e9c763344},
139\,991 trimmed curves, \texttt{SI\_UNIT(.MILLI.,.METRE.)}) is converted to
metres. After identity mapping, \(X\in[0,4270.609]\)\,m and
\(Z_{\max}=350.312\)\,m. The written deck has 51\,896 nodes and 30\,317
elements (7\,702\,117 bytes). CalculiX CrunchiX 2.21, executed on a copy of
hash \texttt{82548e6a}, dies while reading the first initial-stress row.

\paragraph{Outlook.}
A later run may emit a CalculiX-legal stress card without silently mutating
this hash. North physical anchors lie outside this STEP and remain proxies.
Fourteen-mode comparison stays forbidden until a solved spectrum exists.

\section{Related work and isolation protocol}
\label{sec:iso}

\paragraph{Related work.}
Agentic FEA here means a scripted, auditable chain with frozen constants, not a
chat that invents sections. Dhondt's CalculiX is used as the open solver
because its keyword deck is inspectable and its version is pinned. Abaqus-like
ELSET-wide uniaxial prestress is a common authoring convenience; it is not the
CalculiX 2.21 contract.

\paragraph{Method.}
Isolation rules, taken from theory v1.2 \S1 and the skill file:
\begin{enumerate}
\item STEP supplies coordinates only.
\item Properties come from DRW-A/B, CALC-INPUT, STD, or a named ASSUMP.
\item \texttt{TARGET-FREQ} lives in \texttt{catwalk-fem/isolated/} and is not
imported by \texttt{write\_inp} or the solver deck.
\item Formed sag is \(h=227.300\)\,m (\(340.600-113.300\)). The \(255.56\)\,m
main-cable control sag is forbidden in the deck (verified absent).
\item The two decks keep independent degrees of freedom; no mirror constraint.
\item Floor-rope anchors and portal-rope anchors are never unioned.
\item After SHA-256 \texttt{82548e6a} is frozen, the \texttt{.inp} is not
rewritten to ``make the solver happy''.
\end{enumerate}

\paragraph{Experiment.}
The isolated file lists fourteen frequencies starting at \(0.0296\)\,Hz. A
full-text search of the frozen deck finds neither \(0.0296\) nor \(255.56\).
\texttt{write\_inp.py} does not import \texttt{isolated/TARGET-FREQ.json}.
The STEP sibling \texttt{cw\_S10\_0716t050342\_a4\_eq.db} is listed as a
forbidden source in the heading.

\paragraph{Outlook.}
Isolation is a scientific claim, not a courtesy. Any later comparison table
must load TARGET-FREQ only after the deck, the solve, and the mode-shape
classification are frozen.

\paragraph{Related work.}

\section{Ingestion and classification (N02--N07)}
\label{sec:ingest}

\paragraph{Related work.}
A centre-line STEP of 139\,991 trimmed curves is not a member-role model. Role
assignment has to be recovered from geometry against drawing lattices.

\paragraph{Method.}
\texttt{parse\_step} stream-parses \texttt{CARTESIAN\_POINT} /
\texttt{TRIMMED\_CURVE}, checks the STEP SHA-256, and scales millimetres to
metres. \texttt{classify\_segments} labels floor ropes by the drawing
\(y=\pm(21.45\pm(0.85+0.26k))\) lattice, long high members as portal/handrail
ropes, short transverse members as \texttt{portal\_or\_beam}, and long
inter-deck members as \texttt{cross\_passage}.

\paragraph{Experiment.}
Raw counts: \texttt{floor\_rope} 43\,200, \texttt{portal\_or\_beam} 4\,719,
\texttt{portal\_rope} 356, \texttt{cross\_passage} 0, \texttt{short\_other}
91\,618. No single segment has \(\Delta y\ge 15\)\,m, because each
\(49.655\)\,m passage is tessellated into \(\approx 1.7\)\,m pieces. At every
drawing passage \(X\), node \(Y\) already spans \([-24.3,24.3]\)\,m. Detection
therefore uses \(Y\)-span, not a single long beam. Unclassified
\texttt{short\_other} is dropped from the coarsened deck. Longitudinal chains
keep drawing stations and a 12\,m target spacing.

\paragraph{Outlook.}
Portal-rope classification remains incomplete after coarsening (227 elements).
That bound is reported in \S\ref{sec:results} and is not hidden by the 142
frame count.

\section{Materials, disjoint anchors, and cable seed (N08--N10)}
\label{sec:anchors}

\paragraph{Related work.}
Theory v1.2 \S4 forbids using a floor-rope anchor as a portal-rope anchor.
The two families differ by \(21\)\,m at the north end and by \(15.332\)\,m at
the south end.

\paragraph{Method.}
Rope \(E=1.20\times 10^{11}\)\,Pa, floor/portal \(A=1400.42\times 10^{-6}\)\,m\(^2\),
\(\mu=12.038\)\,kg/m (CALC-INPUT / DRW-A). Steel \(E=2.06\times 10^{11}\)\,Pa,
\(\rho=7850\)\,kg/m\(^3\). Horizontal seed
\[
H=\frac{wL^2}{8h},\qquad h=227.300~\mathrm{m},\qquad L=2286.642~\mathrm{m}.
\]
Per deck, \(w_{\mathrm{floor}}=2.766\)\,kN/m and
\(w_{\mathrm{portal}}=0.709\)\,kN/m give \(H_{\mathrm{floor}}=7.954\)\,MN and
\(H_{\mathrm{portal}}=2.039\)\,MN. Axial seeds are
\(\sigma_{\mathrm{floor}}=3.549611\times 10^{8}\)\,Pa and
\(\sigma_{\mathrm{portal}}=2.426295\times 10^{8}\)\,Pa. L0 wave frequency
\(f_1=\sqrt{g/32h}=0.036719\)\,Hz is a magnitude gate only.

Floor and portal anchors use different node sets and two \texttt{*BOUNDARY}
cards. A third card holds saddles and nominal ends.

\section{Solver deck and the CalculiX 2.21 initial-stress gate (N12--N14)}
\label{sec:ccx}

\paragraph{Related work.}
CalculiX CrunchiX 2.21 (\S6.11.7 and \S7.76 of the User's Manual) defines
\texttt{*INITIAL CONDITIONS, TYPE=STRESS} before the first \texttt{*STEP}. If
\texttt{USER} is not specified, each data line is
\begin{quote}
element number; integration point number; \(S_{xx}\), \(S_{yy}\), \(S_{zz}\),
\(S_{xy}\), \(S_{xz}\), \(S_{yz}\)
\end{quote}
in the global rectangular frame, as second Piola--Kirchhoff components.
Abaqus-style ELSET plus a single axial stress is not that contract.

\paragraph{Method.}
The writer currently emits
\begin{lstlisting}
*INITIAL CONDITIONS, TYPE=STRESS
E_FLOOR_ROPE, 3.549611e+08
E_PORTAL_ROPE, 2.426295e+08
\end{lstlisting}
at lines 90863--90865 of the frozen deck. That is ELSET + uniaxial. The hash
\texttt{82548e6a} is frozen: the file is not patched. CalculiX is run only on
a copy under \texttt{/tmp/ccx-82548e6a/}. The original is re-hashed before and
after.

\paragraph{Experiment.}
A lexical audit (\texttt{artifacts/ic\_format\_audit.json}) classifies both
rows as \texttt{elset\_plus\_uniaxial=true} and
\texttt{ccx\_2\_21\_legal=false}. The formatted floor stress
\texttt{3.549611e+08} equals the writer's
\(\sigma_{\mathrm{floor}}=H_{\mathrm{floor}}/(16A)\).

CalculiX 2.21 (\texttt{ccx -v}: ``This is Version 2.21'') was executed on the
copy. The solver printed
\begin{lstlisting}
*ERROR reading *INITIAL CONDITIONS. Card image:
       E_FLOOR_ROPE,3.549611E+08
...
*ERROR in calinput: at least one fatal
       error message while reading the
       input deck: CalculiX stops.
\end{lstlisting}
and exited 201. Observed artefacts: no \texttt{job.frd}; \texttt{job.dat} has
0 bytes; \texttt{job.sta} and \texttt{job.cvg} contain the printed table
headers only. Wall-clock time on this host was \(0.738\)--\(0.815\)\,s,
matching the given bound \(<1\)\,s. The banner ``number of:'' block is
explicitly ``estimated upper bounds'' issued while reading the deck; no
assembled equation count appears. The original file hash after the run is
still \texttt{82548e6a\(\ldots\)276ab6da}.

These facts were first given as an external solve on the same hash and were
then reproduced locally. Both records are stored in
\texttt{artifacts/ccx\_run\_82548e6a.json} and the copied logs
\texttt{ccx\_82548e6a.stdout.txt}, \texttt{.sta}, \texttt{.cvg}, \texttt{.dat}.

\paragraph{Outlook.}
A later deck may expand each tension element into an eight-field stress row
without claiming that this frozen hash already did so. Expanding the card is a
new artefact with a new hash. This paper does not perform that rewrite.

\section{Discussion and conclusions}
\label{sec:disc}

\paragraph{Related work.}
Pull request \#18 shipped an empty \texttt{artifacts/} directory. Pull request
\#19 first deposited the hashed deck. This run adds the 142-frame ledger, the
CalculiX 2.21 parse record, and a complete paper, without changing
\texttt{82548e6a}.

\paragraph{Method.}
Limits that remain visible in the evidence are stated as bounds, not as
hidden FAIL marks. Hard gates (identity transform, 21/142, disjoint anchors,
complete keywords, frozen hash, forbidden sources) all close.

\paragraph{Experiment.}
Bounds:
\begin{itemize}
\item North anchors are STEP-end proxies, not \(K16+852\) / \(K16+831\).
\item Portal-rope classification is incomplete (227 coarsened elements);
south portal nodes come from \texttt{portal\_or\_beam} at \(x=4221.093\).
\item Geometric sag \(214.18\)\,m versus \(227.30\)\,m is inside the 15\,m
gate but is not a formed-line fit.
\item Floor-line length is about 20\,\% above a four-span catenary estimate.
\item The stress card is not CalculiX-legal. The solver never assembled a
system. No spectrum exists.
\end{itemize}

\paragraph{Outlook.}
The next scientific step is a new hashed deck whose \texttt{TYPE=STRESS} rows
are element number + integration point + six stresses, followed by a real
nonlinear static solve, and only then a TARGET-FREQ comparison. That step is
outside this frozen hash.
