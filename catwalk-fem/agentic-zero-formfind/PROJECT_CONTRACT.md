# 项目合同：Agentic Catwalk CCX Zero-Form

## 1. 目标

建立一条能够由 Agent 规划、生成、检查、执行、诊断和迭代的猫道 CalculiX 建模链。当前阶段只验证“零导入预应力找形”是否具备可执行结构，不追求附件频率对齐或抖振结果。

## 2. 允许使用的事实

- 图纸和复核报告中的坐标、跨度、垂度、截面、材料和恒载；
- Release STEP 的中心线几何；
- MCT 节点坐标，且仅作为几何交叉检查；
- 已公开的求解器失败记录，用于设计微算例和门禁；
- 解析悬链线/抛物线公式，仅作为初值或独立量级审计。

## 3. 禁止输入

- MCT `*INIFORCE`、初始轴力表或初应力；
- S10 DB 中继承的应力、约束和模态补丁；
- 附件频率作为优化目标或参数反标依据；
- 为消除零模态而施加的全网 UY、临时弹簧或未批准梁弯曲刚度；
- 未登记的“最新文件”；
- 任何没有 sourceRef/assumptionRef 的质量、阻尼或气动参数。

## 4. 找形合同

独立控制量为端点、目标加载几何和恒载。无应力参考几何、平衡索力和支反力是求解结果。

每次外层迭代都必须：

1. 建立新的 run/iteration ID；
2. 从零导入轴向应力开始；
3. 保留输入、deck、命令、日志和结果哈希；
4. 撤除所有临时成形控制；
5. 检查几何误差、力残差、正索力和反力闭合；
6. 通过无新增荷载保持；
7. 失败时不覆盖上一轮工件。

## 5. 动力合同

动力只有在 G8B 和 G11 通过后才能进入 `PREPARED`。抖振只有在切线模态、零荷载瞬态、微振幅自由衰减、振幅序列和确定性荷载全部通过后才能进入 `ARMED`。

## 6. 结论边界

任何输入生成、lint、进程退出码、FRD 产生、频谱峰或求解器“Job finished”都不能单独证明工程有效。结论必须绑定：

- 输入 SHA；
- 求解器及可执行文件 SHA；
- 状态继承；
- 原始结果；
- 门禁数据；
- 独立复核；
- 明确允许用途。
