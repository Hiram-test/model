# 自动化与准确性架构

## 1. 中间表示

整条链路使用一个求解器无关的有限元中间表示 `FEM-IR`。CAD、PDF、IFC、Excel、计算书和现场资料先进入证据图，随后再生成 FEM-IR。求解器适配器只读取 FEM-IR，不直接解析图纸。

FEM-IR 至少包含：

- 项目、分析目标、单位制和全局坐标系；
- 材料、截面、节点、线、面、体和参考几何；
- 单元、局部坐标、偏心、刚臂、连接、释放和支承；
- 初张力、初应变、预应力、线形和施工初始状态；
- 荷载工况、组合、施工阶段和输出请求；
- 每个对象的来源、假定、决策、版本和验证目标。

## 2. 数据可信度

每个数值字段使用统一 quantity 结构：

```json
{
  "value": 12.5,
  "unit": "m",
  "basis": "drawing-dimension",
  "sourceRefs": ["EV-000231"],
  "assumptionRef": null
}
```

所有转换保留原始值、原始单位、转换公式、程序版本和时间戳。坐标值还要记录坐标系 ID。无量纲值也要标记 `unit: "1"`。

## 3. 证据图

证据图将原始资料与模型对象连接起来。证据节点包括：

- CAD entity handle、layer、block、xref 和 layout；
- PDF page、bounding box、view 和文字片段；
- 图像像素区域、标定比例和识别置信度；
- 材料表、工程量表、计算原则、专项方案和规范条文；
- 经批准的工程假定和参数范围。

每个模型对象至少拥有一个 `sourceRef` 或 `assumptionRef`。没有证据入口的对象进入 orphan audit。

## 4. 自动化边界

语言模型适合执行跨图语义对应、构件角色判断、传力路径推理、抽象方案选择、冲突解释和报告组织。确定性程序适合执行解析、几何运算、矩阵检查、单位换算、公式计算、求解器调用和阈值判断。

任何由语言模型生成的数值先写入候选区，经过 schema、单位、范围、来源和独立公式检查后才能进入正式模型。

## 5. 质量门与阻断

质量门状态只有四种：

- `PASS`：满足全部强制条件；
- `PASS_WITH_BOUNDS`：缺失信息已形成有依据的参数边界，所有控制响应在边界内满足验收条件；
- `BLOCKED`：关键证据、物理表达或数值可靠性不足，下游停止；
- `NOT_APPLICABLE`：分支在当前分析范围内不触发。

节点可产生确定的工程处置，同时仍允许质量门阻断最终发布。例如连接刚度未知时，抽象节点可以确定采用参数化弹簧；若合理范围内的响应跨越验收限值，质量门进入 `BLOCKED`。

## 6. 双重校核

关键输出至少使用一种独立方法复核：

- 简化解析模型或手算；
- 不同单元离散或不同网格；
- 不同求解器；
- 局部自由体平衡；
- 实测、试验或既有经审查模型；
- 对称性、反对称性、量纲和极限情形。

独立复核的输入和实现不得完全复用主模型代码路径。共享同一错误源的两次计算不能计作独立证据。

## 7. 变更控制

每个工件记录上游哈希。图纸、规范、假定或求解器版本改变时，节点 18 沿依赖图计算受影响节点。局部变更可以只重跑受影响子图，但 G11、G13、G15 和 G16 必须重新评估，确保整体平衡和允许用途仍成立。

## 8. 发布边界

发布包要明确：

- 模型允许支持的决策；
- 已覆盖的桥型、阶段、荷载和响应；
- 未覆盖的局部行为；
- 高敏感假定和包络；
- 尚未验证的求解器功能；
- 工程签认人、日期和版本；
- 任何超出允许用途的使用都会触发新 run。
