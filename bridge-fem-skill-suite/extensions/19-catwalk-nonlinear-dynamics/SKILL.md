# 任务

你负责把已经通过静力初始状态门的猫道模型扩展为可审计的动力验证链。研究对象不是一个脱离静力状态的抽象特征值模型，而是同一物理结构在同一平衡态附近的小扰动响应及其有限振幅延拓。

本 Skill 必须区分：

1. 平衡态切线模态：零振幅极限下的线性摄动特征值；
2. 有限振幅自由振动：频率、空间形态和耦合可能随振幅变化；
3. 受迫动力响应：确定性荷载或随机抖振作用下的时域/频域响应；
4. 气动失稳：气动力做功、结构耗能和响应增长率共同决定的稳定性问题。

# 激活条件

只有同时满足下列条件，本 Skill 才能从 `NOT_ARMED` 转为 `PREPARED`：

- N10/G8B 已经通过，初始状态同时满足几何误差、力残差、正索力和无新增荷载保持；
- N13/G11 已经通过，质量、转动惯量、约束、连通、刚体模态和单位测试闭合；
- N14 求解器映射已冻结，静力基态能够在同一作业或经验证的 restart 契约中重建；
- 动力所需的质量、阻尼、气动系数、采样率、时间步和输出测点均有 sourceRef 或 assumptionRef；
- 任何已知求解器特性缺口已有独立微算例，不允许以全模型试错代替。

若任一条件缺失，本 Skill 输出 `NOT_ARMED` 或 `BLOCKED`，不得生成可执行的完整抖振任务。

# 输入契约

必须读取：

- 已接受的 `initial_state_ir`、平衡态结果和无新增荷载保持证据；
- 完整 FEM-IR、质量与转动惯量台账、连接和边界 IR；
- 求解器 feature mapping 与静力 restart/state-inheritance 证明；
- 切线模态提取计划、目标测点和模态分类规则；
- 阻尼模型及其适用频段；
- 自由衰减扰动定义、振幅序列和停止条件；
- 确定性动力荷载或随机风场定义；
- 时间步、总时长、采样率、滤波和频率识别方案；
- 能量平衡、状态漂移和数值稳定门限；
- 独立复核计划。

严禁读取目标频率并据此修改刚度、质量、边界或初始状态。附件频率只能进入最终比较，不能进入模型生成和参数反标。

# 不可违反的规则

1. 禁止从未通过 G8B 的静力 DB、RST、FRD 或中间子步直接进入动力。
2. 切线模态必须围绕同一个已接受平衡态建立；不得把无预应力初始几何上的普通特征值称为猫道固有模态。
3. 切线模态是零振幅基准，不能自动代表有限振幅自由振动。
4. 第一个时域工况必须是零新增荷载瞬态；该工况漂移或发散时，禁止继续自由衰减和抖振。
5. 自由衰减必须采用可追溯的空间扰动，优先使用切线振型或成对断面位移/速度；禁止用单点任意位移后只看单通道 FFT。
6. 有限振幅研究必须建立振幅序列，并检查频率、空间形态、相位和模态耦合随振幅的变化。
7. 当振幅趋近于零时，自由衰减识别频率应趋近切线模态；若不满足，先检查状态继承、质量、时间积分和信号识别。
8. 质量总量相同不等于动力等效。质心、横向分布、转动惯量和与结构节点的运动约束必须闭合。
9. 不得把点质量折入索密度作为生产动力模型的默认替代；任何等效只允许在明确受限的微算例中使用。
10. 不得用全网平动约束、模态专用弹簧或梁单元弯曲刚度消除零模态而不改变物理合同。
11. 数值阻尼、Rayleigh 阻尼、质量缩放和稳定化不得用于掩盖零荷载漂移或气动力符号错误。
12. 时间步、采样率和总时长必须覆盖最高关注频率、最低关注频率及足够衰减周期，并进行敏感性检查。
13. 频率识别至少由两种方法交叉核对，例如 FFT/PSD 与 Prony、ERA、Hilbert 或时频脊线。
14. 随机抖振只能在确定性单点、单断面和小比例空间荷载依次通过后解锁。
15. 求解器返回正常、时程能输出或频谱有峰值均不等于动力结果通过。

# 工作顺序

## DX00：动力资格与状态合同

冻结动力输入的唯一静力平衡态、作业名、结果文件、restart 文件、求解器版本和哈希。证明动力作业重建后：

- 几何坐标与接受状态一致；
- 索力、支反力和质量台账一致；
- 约束和连接没有切换；
- 临时找形约束已经移除；
- 没有残留模态专用稳定对象。

输出 `dynamic_state_contract.json`。不能证明时 `DG0=BLOCKED`。

## DX01：质量与惯量动力审计

逐项核对分布质量、点质量、偏心质量和转动惯量。至少输出：

- 总质量与三向质心；
- 断面横向质量二阶矩；
- 关于纵桥轴的极惯性代理；
- 每类附属质量的节点映射；
- 质量约束与主结构运动之间的关系；
- 求解器质量关键字的微算例结果。

只有总量、位置和运动约束同时闭合，`DG1` 才允许通过。

## DX02：平衡态切线模态

从接受状态提取切线模态，保存特征值、振型、参与因子、广义质量和测点响应。模态分类必须依据空间形态、相位、半波数和能量分布，不得只按频率顺序贴标签。

若出现近零模态，必须判断其属于物理刚体、单元内部机制、约束遗漏还是数值伪模态。禁止直接删除后继续宣布谱有效。

## DX03：零新增荷载瞬态

在同一静力状态上打开时间积分，不施加新动力荷载和初始扰动。检查：

- 位移和索力漂移；
- 动能是否无故增长；
- 外力做功、应变能和阻尼耗能平衡；
- 约束反力和总动量；
- 时间步敏感性。

漂移超过门限时 `DG3=BLOCKED`，问题返回状态继承、边界、质量或积分节点。

## DX04：微振幅自由衰减

沿选定切线模态或明确的断面运动施加微小初始速度/位移，随后完全移除临时控制。至少同步读取多个跨中和四分点断面的：

- 两幅平均横向位移；
- 两幅平均竖向位移；
- 两幅差分扭转角；
- 关键索力；
- 动能、应变能和耗能。

微振幅识别频率与切线模态不一致时不得进入大振幅。

## DX05：振幅序列与非线性骨架

按预先冻结的振幅序列重复自由衰减，输出：

- 振幅—频率曲线；
- 振幅—阻尼曲线；
- 振型/相位随振幅的变化；
- 能量在弯曲、扭转和索力分支间的转移；
- 模态内部共振或跳跃迹象。

单次大位移释放不能被称为非线性模态识别。

## DX06：确定性动力荷载烟测

按下列顺序增加复杂度：

1. 单节点平滑正弦荷载；
2. 单断面成对荷载；
3. 多断面同相荷载；
4. 小比例空间风荷载；
5. 设计比例确定性荷载。

每一级检查方向、相位、总力、总矩、做功和响应数量级。任一级失败即停止。

## DX07：随机抖振与气动稳定

只有 `DG0–DG6` 全部满足授权条件，才能建立随机风场和气动力反馈。必须证明：

- 风速谱、相干函数、空间离散和随机种子可重放；
- 气动力系数、导数、符号和坐标转换有来源；
- 结构阻尼与气动阻尼不重复；
- 载荷总力和总矩与断面定义一致；
- 响应统计已达到平稳或明确标记非平稳；
- 气动力做功、结构耗能和响应增长率相互一致。

# 动力质量门

- `DG0`：静力状态与动力状态合同闭合；
- `DG1`：质量、质心、转动惯量和运动约束闭合；
- `DG2`：切线模态没有未解释近零机制，模态身份可追溯；
- `DG3`：零新增荷载瞬态稳定且能量不无故增长；
- `DG4`：微振幅自由衰减趋近切线模态；
- `DG5`：振幅序列、时间步和阻尼敏感性完成；
- `DG6`：确定性动力荷载逐级通过；
- `DG7`：随机抖振输入、能量和统计验证通过。

`DG0–DG6` 任一为 `BLOCKED` 时，`buffeting_authorization.state` 必须保持 `NOT_ARMED`。

# CalculiX 专项门

1. 在全模型前单独验证 `*MASS`/集中质量与预应力 `*FREQUENCY` 的兼容性；已知 `add_bo_st` 类错误不能通过质量折密度静默绕过。
2. T3D2、B31 或其他索表达必须按保留物理选择。B31 引入弯曲刚度，不能只因为特征值更稳定就替代索单元。
3. 若 `TOTALS` 或反力输出存在版本缺陷，必须用独立节点反力和外载合力复核，不得以 Newton 残差代替全局平衡。
4. 近零模态必须在约束矩阵、连通图和微算例层定位；不得先删除模态再把剩余谱标为有效。
5. 静力—频率—瞬态状态继承必须通过独立小模型证明，不能仅凭关键字语法推断。
6. 每个 CCX 版本、编译选项、线程数和可执行文件哈希必须登记。

# 失败处理

- 零荷载漂移：返回 DX00、N09、N10 或 N13；
- 质量/扭转异常：返回 DX01 或 N08；
- 近零模态：返回 N07、N09、N12 或求解器 feature micro-test；
- 微振幅与切线模态不一致：返回状态继承、时间积分、输出采样或信号识别；
- 大振幅频率变化：保留为物理候选，但必须通过时间步、能量和空间振型复核；
- 随机荷载首步爆炸：先退回确定性载荷和零荷载瞬态，不得直接修改阻尼或荷载比例后继续；
- 求解器缺陷：形成 feature gap，不得改写工程物理隐藏缺陷。

每次失败必须写入 `dynamic_failure_ledger.json`，包括最早失败节点、输入哈希、求解器版本、最小复现、禁止的错误修复和下一次允许尝试。

# 完成检查

1. 是否证明动力状态与接受静力状态完全一致？
2. 是否同时核对质量总量、空间位置和转动惯量？
3. 是否把切线模态与有限振幅自由振动分开？
4. 是否先完成零新增荷载瞬态？
5. 微振幅自由衰减是否趋近切线频率？
6. 是否建立振幅、时间步和阻尼敏感性？
7. 是否使用多测点空间响应识别模态？
8. 是否逐级完成确定性动力荷载烟测？
9. 抖振是否保持 fail-closed 授权？
10. 是否保存全部原始结果、日志、参数和失败最小复现？
