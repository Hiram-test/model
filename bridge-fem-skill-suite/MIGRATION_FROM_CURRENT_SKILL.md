# 现有 bridge-cad-fem-abstraction Skill 评审与迁移

## 已有优势

原 skill 在有限元工程抽象这一节点具备较强完整性：

1. 以传力路径和目标响应组织决策，避免按制造零件机械建模。
2. 使用“显式建模、等效计入、仅计质量/荷载、不纳入”四类闭合处置。
3. 强制说明等效参数、舍弃细节和验证方法。
4. 对索体系、支承、连接刚度和初张力等缺失信息采用参数化表达。
5. 包含桥型先验、质量重复检查、Part 映射和排除审计。

这些内容应保留，并放在整条流程的第 06 节点。

## 需要补齐的接口

原 skill 默认上游已经提供可靠图纸事实。实际自动化需要先完成文件版本、图纸坐标、文字与表格提取、跨图一致性、部件去重和证据定位。缺少这些上游节点时，抽象结论难以稳定复现。

原 skill 的输出主要面向人工阅读。新版本增加稳定 ID、sourceRefs、assumptionRefs、模型用途、参数边界、下游 representation contract 和质量门状态，使节点 07 能直接生成求解器无关的几何与拓扑。

原 skill 对缺失信息要求继续作出唯一处置，这一规则适合抽象分类。工程发布还需要单独的 gate 机制：参数边界内均满足验收条件时可 `PASS_WITH_BOUNDS`；边界跨越验收限值时进入 `BLOCKED`。

## 新增的下游闭环

抽象之后新增以下节点：

- 参数化几何与拓扑；
- 材料、截面和质量；
- 连接、支承和边界；
- 索系找形与初始状态；
- 荷载、组合和施工阶段；
- 单元、网格和数值控制；
- 求解前检查、求解器运行、解验证；
- 静力响应和规范复核；
- 独立复核、敏感性和可信度；
- 报告、审计和变更控制。

## 迁移结果

新版位于 `skills/06-bridge-cad-fem-abstraction/SKILL.md`。原有工程判断框架得到保留，新增上游输入契约、证据字段、质量门和下游 FEM-IR 映射。原文件可以作为领域知识底稿，不再独立承担端到端流程。
