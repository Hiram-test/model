# ID、单位与坐标规则

| 对象 | 前缀 |
|---|---|
| 项目 | PRJ- |
| 运行 | RUN- |
| 工件 | ART- |
| 原始文件 | SRC- |
| 图纸页/布局 | SHEET- |
| 视图 | VIEW- |
| 证据 | EV- |
| 制造零件 | PART- |
| 工程构件组 | CG- |
| 假定 | ASSUMP- |
| 问题 | ISSUE- |
| 材料 | MAT- |
| 截面 | SEC- |
| 节点 | NODE- |
| 单元 | ELEM- |
| 连接 | CONN- |

| 初始状态 | ISTATE- |
| 荷载工况 | LC- |
| 组合 | COMB- |

| 检查 | CHK- |
| 求解运行 | SOLVE- |

ID 在项目内稳定。对象改名不改变 ID；对象拆分或合并必须生成新 ID，并记录 `derivedFrom`。

## 单位

1. 项目在 G0 冻结一个内部单位制，推荐 SI。
2. 每个数值由 `value`、`unit`、`basis`、`sourceRefs` 组成。
3. 力与质量严格区分；重力加速度作为显式项目参数。
4. 温度值和温差使用不同 quantity type。
5. 角度必须带 `deg` 或 `rad`。
6. 密度、重度、面质量和线质量不得混用。
7. 求解器适配器负责内部单位到求解器单位的唯一转换，并输出转换审计表。
8. 输出结果在报告层可以转换显示，原始结果保存求解器单位和内部统一单位两份。

## 坐标

1. 建立全局坐标系、桥轴坐标系、构件局部坐标系和图纸视图坐标系。
2. 所有变换使用齐次变换矩阵并保存方向、原点和尺度。
3. 任何几何值必须指向坐标系 ID。
4. 梁、索、壳单元记录局部轴方向；方向翻转要触发内力符号检查。
5. CAD 块、xref 和 PDF 视图的嵌套变换必须展开并保留原始层级。
6. 坐标合并容差作为项目参数，禁止由求解器默认值隐式决定。
