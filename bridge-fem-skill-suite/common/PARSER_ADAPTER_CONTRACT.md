# 图纸与资料解析器适配契约

每个 CAD、PDF、图像、表格或文档解析器在 tool registry 中登记以下字段：

- adapterId、version、executable/container hash；
- 支持格式、版本、压缩、加密和外部参照能力；
- 向量、文字、块、属性、图层、布局、表格和元数据支持；
- 单位、坐标、比例、字体替换和编码策略；
- source locator 生成规则；
- 解析失败、部分成功和不支持特性的错误码；
- 输出 schema 与字段语义；
- 资源限制、安全沙箱和网络政策；
- 黄金文件、错误注入和回归测试结果。

## 解析优先级

1. 原生结构化/API 读取；
2. 向量与文字对象解析；
3. 几何标定后的图像理解；
4. OCR 仅用于没有可用文字层或结构化对象的区域，并保留低置信度和人工核验要求。

## 双解析器策略

关键尺寸、材料表或连接说明可以由两个独立解析器提取。系统比较数值、单位、文本和 source locator；差异超过预设阈值进入 conflict register，不自动投票选值。

## 安全要求

解析在隔离目录和最小权限下执行。禁用宏、嵌入脚本、外部链接和自动下载。所有临时文件、命令、日志和退出码进入 run record。
