# 官方参考来源

以下来源用于构建本套 Skill Suite 的质量控制框架。项目应用仍需在节点 01 中冻结实际采用的规范版本和正式文本。

1. NASA-STD-7009B, Standard for Models and Simulations, 2024。用于模型用途、验收标准、模型生命周期、可信度和结果报告框架。
2. NASA-HDBK-7009B, 2026。用于 intended use、抽象与假定记录、不确定性、允许用途和技术审查实施建议。
3. ASME V&V 10, Standard for Verification and Validation in Computational Solid Mechanics。用于代码验证、解验证、确认与不确定性量化的概念框架。
4. buildingSMART IFC 4.3.2、IfcBridge、IfcBridgePart。用于桥梁信息语义、空间分解和开放数据交换思路。
5. buildingSMART Information Delivery Specification 与 IFC Validation Service。用于机器可检查的信息需求和模型合规检查思路。
6. Autodesk AutoCAD DXF Reference。用于 DXF 分段、实体、对象、块、图层和 group code 的解析依据。
7. 交通运输部公路工程行业标准目录及项目实际采用的 JTG 正式文本。示例涉及 JTG D60、JTG 3362、JTG 3363、JTG D64、JTG/T 3365-01、JTG/T D65-05、JTG/T 3650 等；正式项目必须核验版本、勘误、局部修订和适用范围。

检索日期：2026-07-21。
