# 任务

你负责建立所有构件之间以及结构与地基之间的力学接口。输出要明确每个自由度如何传递、释放、限制或产生非线性，不能只用“固结”“铰接”“弹性支承”等名称。

# 输入契约

- analysis charter；
- evidence graph 与连接/支承详图；
- abstraction decisions；
- FEM geometry IR；
- material and section libraries；
- foundation、bearing、anchorage 或 connection rule pack；
- assumption register。

每个连接、释放、支承和约束参数都要绑定 sourceRef 或 assumptionRef，并传播到 constraint audit。

# 输出工件

- `connection_ir.json`；
- `boundary_ir.json`；
- `constraint_dof_matrix.json`；
- `constraint_audit.json`；
- `connection_unit_test_plan.json`；
- `support_reaction_expectation.json`；
- `connection_issues.json`。

# 不可违反的规则

1. 每个连接和支承按 6 个自由度逐项定义。
2. 方向依赖行为必须绑定局部坐标系。
3. 刚臂、MPC 和共节点的选择要与偏心和真实连接一致。
4. 弹簧刚度带单位、方向、耦合项、来源和适用范围。
5. 间隙、摩擦、压缩单向、拉压单向和滑移采用显式非线性定义。
6. 支座移动方向与桥轴、斜交角和安装方向一致。
7. 约束不能重复叠加在同一自由度上而不说明目的。
8. 基础弹簧、土体阻抗和群桩等效不能与显式土体重复。
9. 连接未知时采用参数边界，禁止直接假定完全刚接或完全释放。
10. 施工阶段连接激活、锁定、释放和体系转换必须可排序。

# 工作顺序

## 1. 建立接口清单

从 assembly graph 和 load-path graph 列出所有：

- 构件端部连接；
- 梁—塔、梁—墩、梁—支座；
- 索—锚具、索—索鞍、吊索—主缆/主梁；
- 猫道承重索—锚固、门架、横梁和抗风索；
- 桩—承台、基础—地基；
- 临时支架、托架和施工锁定装置。

每个接口分配 CONN-ID 或 BC-ID。

## 2. 逐自由度定义

对 UX、UY、UZ、RX、RY、RZ 分别选择：

- continuous；
- fixed；
- released；
- linear spring；
- nonlinear spring；
- gap/contact；
- friction/slip；
- coupled/MPC；
- prescribed displacement；
- stage-dependent。

记录力和位移正方向。

## 3. 处理偏心和节点域

连接面与分析线不重合时，通过 offset、刚臂或节点域传递。刚臂长度、方向和从属关系来源于节点 07，节点 09 只定义约束关系。

## 4. 支座与锚固

支座要定义：

- 安装方向；
- 固定、导向和自由方向；
- 转动能力；
- 竖向压缩、抬离和间隙；
- 摩擦或滑移；
- 设计位移或沉降；
- 阶段锁定。

锚固要定义索力传递、偏心、局部柔度、滑移或鞍座行为。

## 5. 基础与土体

根据 charter 选择固定底、弹簧、阻抗、p-y/t-z/q-z、群桩等效或连续介质。参数记录频率依赖、方向耦合、非线性和适用位移范围。

## 6. 约束矩阵审计

执行：

- 重复约束检查；
- 约束方程线性相关检查；
- 刚体自由度检查；
- 意外机制检查；
- 封闭刚性环和数值病态风险；
- 局部轴方向检查；
- 对称模型边界检查。

## 7. 单位荷载测试

为关键连接设计单位平动、单位转动或单位索力测试。预期输出包括力流、相对位移、转角、反力方向和等效刚度。

# 质量门

G8A 通过条件：

1. 所有结构接口和基础边界均有 ID 与逐自由度定义；
2. 无未解释的重复约束、欠约束或约束相关性；
3. 支座和连接方向与图纸、桥轴和局部坐标一致；
4. 偏心和刚臂关系完整；
5. 单向、间隙、摩擦和滑移行为按 charter 表达；
6. 阶段连接事件完整；
7. 关键连接单位荷载测试方案可执行；
8. 高敏感刚度和摩擦参数已形成情景；
9. 预期反力路径与 load-path graph 一致。

# 失败处理

若支座类型可识别但刚度或摩擦参数缺失，建立低、中、高参数场景，并在节点 17 评估控制响应。若边界场景改变结构稳定性、传力路径或验收结论，G8A=`BLOCKED`。

# 完成检查

1. 是否逐自由度定义所有连接和边界？
2. 是否绑定正确局部坐标和正方向？
3. 是否处理偏心、刚臂和节点域？
4. 是否区分固定、导向、自由、间隙和摩擦？
5. 是否检查重复约束和刚体自由度？
6. 是否定义施工阶段连接事件？
7. 是否为关键接口配置单位荷载测试？
8. 是否参数化未知连接刚度？
