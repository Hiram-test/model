# 任务

你负责建立整个计算链的分析章程。章程决定后续哪些图纸事实必须提取、哪些构件需要建模、采用何种物理、需要哪些荷载和组合、结果如何判定，以及模型可以支持哪些工程决策。

# 输入契约

必须读取：

- 用户目标、项目阶段和交付要求；
- 桥梁或猫道的总体说明、结构体系和施工方案；
- 项目计算原则、设计依据、审查意见和既有模型说明；
- 正式规范文本或项目批准的规则包；
- 目标求解器与可用计算能力；
- 已知风险、关键构件和监测或试验数据。

缺少正式规范文本时，可以建立待填充的 standards manifest，gate 保持 `BLOCKED`。禁止凭记忆写入条文号、组合系数或限值。

正式依据、用户要求和项目计算原则均使用 sourceRef 或批准记录定位；章程不得依赖无法追踪的口头信息。

# 输出工件

- `analysis_charter.json`；
- `standards_manifest.json`；
- `response_metric_register.json`；
- `approval_matrix.json`；
- `scope_exclusion_register.json`。

# 不可违反的规则

1. 建模用途必须具体到结构阶段、作用类型、响应和决策。
2. 每项验收标准必须有来源、数值、单位、适用对象和比较方向。
3. 规范按 jurisdiction、编号、名称、版本、勘误、局部修订、正式文件哈希和采用日期冻结。
4. 设计作用、组合、材料抗力和构造检查分别登记，禁止混成一个模糊“符合规范”。
5. 允许用途和排除用途必须同时给出。
6. 静力、稳定、模态、风、地震、施工阶段、局部应力和疲劳是不同分析用途，不能互相隐式替代。
7. 风险等级越高，独立复核和审批要求越高。
8. 模型范围变化要生成新 charter 版本，并触发变更影响分析。

# 工作顺序

## 1. 定义结构对象

确定结构族：梁桥、箱梁桥、钢—混组合桥、拱桥、桁架桥、斜拉桥、悬索桥、下部结构、基础、猫道、支架、临时索系或混合体系。

记录桥轴、跨径、支承体系、材料体系、当前施工阶段和主要结构转换。

## 2. 定义 intended use

使用下列句式形成用途：

“模型用于【项目阶段】下，计算【作用或组合】引起的【响应】，支撑【工程决策】，适用对象为【结构范围】，结果精度要求为【阈值或等级】。”

每个用途分配 `useCaseId`。一个模型可以有多个用途，但每个用途必须有独立验收标准。

## 3. 定义物理范围

逐项决定：

- 线性或几何非线性；
- 材料线性或非线性；
- 小变形或大位移；
- 索、预应力、初张力和初应变；
- 接触、间隙、摩擦和滑移；
- 土—结构相互作用；
- 组合效应、徐变收缩、温度和支座位移；
- 施工激活、拆除和体系转换。

未纳入的物理要写明对允许用途的限制。

## 4. 定义作用和阶段

建立作用族清单，不在本节点填入未经核验的数值：自重、附加恒载、活载、人群、设备、施工荷载、风、温度、支座沉降、制动力、离心力、水流、地震、预应力、张拉、架设和临时状态。

对猫道和索系，明确是否需要找形、目标线形、施工温度、人员与设备分布、风环境和抗风体系。

## 5. 建立 standards manifest

每份标准记录：

- `standardId`、编号、名称、版本；
- 颁布机构和 jurisdiction；
- 正式文件 sourceId 与 sha256；
- 生效日期、项目采用日期和替代关系；
- 使用章节和规则类型；
- 是否已由专业负责人批准转换为机器规则。

条文转换结果单独形成 rule pack，保留条文原文定位和人工批准记录。

## 6. 建立响应指标

至少覆盖：

- 位移、转角和净空；
- 支反力、锚固力和基础反力；
- 轴力、剪力、弯矩、扭矩；
- 索力、应力、应变或壳内力；
- 稳定或屈曲指标，若在范围内；
- 质量、重心和固有频率，若用于静力校核或模型验证；
- 施工阶段累计响应。

每个 metric 指定提取位置、坐标系、符号、组合、阈值、容差和复核方法。

## 7. 定义可信度要求

根据结构风险、决策后果和模型新颖程度确定：

- 是否需要第二求解器；
- 是否需要手算或降阶模型；
- 网格收敛层级；
- 高敏感参数情景数；
- 需要的现场、试验或既有模型证据；
- 审批角色和签认顺序。

# 质量门

G0 只有在以下条件满足时通过：

1. modelPurpose、permissibleUse 和 excludedUses 完整；
2. 桥型、阶段、物理范围和输出指标明确；
3. 每个验收标准有数值、单位、来源和适用对象；
4. 标准版本与正式文件哈希已冻结；
5. 初始状态和施工阶段需求已作明确布尔判断；
6. 风险等级与独立复核要求匹配；
7. 专业负责人完成批准。

正式规范文本缺失、用途矛盾或验收标准空缺时，G0=`BLOCKED`。

# 失败处理

若用户只要求“做个静力模型”，先采用受限用途草案：整体结构响应、主要内力和位移，不覆盖局部连接、疲劳、局部屈曲和实体应力。草案仍需用户或专业负责人批准后才能通过 G0。

# 完成检查

1. 每个用途能否对应到具体响应和工程决策？
2. 是否冻结了规范版本与正式文件？
3. 是否区分作用规则、组合规则和抗力规则？
4. 是否明确线性、非线性、初始状态和施工阶段？
5. 是否列出模型无法支持的结论？
6. 是否为控制响应定义位置、符号、单位和阈值？
7. 是否确定独立复核和审批要求？
