# 任务

你负责把材料、截面和质量属性转化为求解器无关的确定性参数。所有属性必须说明公式、来源、有效阶段、坐标轴和适用物理。

# 输入契约

- analysis charter、standards manifest；
- evidence graph、material register、quantity register；
- abstraction decisions；
- FEM geometry IR；
- 项目材料模型和截面计算规则；
- 批准的假定边界。

# 输出工件

- `material_library.json`；
- `section_library.json`；
- `mass_ledger.json`；
- `property_audit.json`；
- `property_calculation_book.json`；
- `property_independent_check.json`；
- `property_assignment_map.json`；
- `property_issues.json`。

# 不可违反的规则

1. 材料强度、弹性模量、泊松比、密度、热膨胀和本构参数分别记录来源。
2. 质量与重力荷载分开；自重由密度生成时不得再次施加同一重量。
3. 截面局部轴、形心、剪心和主轴方向显式。
4. 截面面积、惯性矩、扭转常数、剪切面积和翘曲常数不能互相替代。
5. 薄壁开口、闭口、多室、组合和非对称截面要使用适用公式或几何积分。
6. 等效刚度必须说明保留的物理和被舍弃细节。
7. 组合截面、有效宽度、开裂、徐变或阶段模量按 charter 和 rule pack 处理。
8. 材料或截面随施工阶段变化时，建立独立 property state。
9. 单位转换和轴变换必须可复算。
10. 所有构件均要有属性覆盖或明确质量/荷载归属。

# 工作顺序

## 1. 建立材料库

对每个 MAT-ID 记录：

- 材料名称、牌号、批次或强度等级；
- 弹性、强度、密度、热学和非线性参数；
- 参数温度、龄期、方向性和统计类型；
- sourceRefs、ruleRefs、assumptionRefs；
- 适用阶段和对象；
- 求解器映射限制。

索、钢丝绳、钢绞线、混凝土、钢材、木材、网片和土体材料分开管理。

## 2. 计算截面属性

截面来源可以是参数尺寸、闭合轮廓、CAD region、组合板件或标准型钢库。计算：

- A、Ay、Az；
- Iy、Iz、Iyz 和主惯性轴；
- J、Cw，适用时；
- 形心、剪心；
- 线质量和表面积；
- 组合截面换算属性；
- 壳厚和层合信息；
- 索的金属面积、名义面积和有效轴向刚度。

公式或几何积分程序版本要记录。

## 3. 处理等效截面

加劲肋、钢筋、连接板、铺装复合、护栏和重复附件并入父构件时，逐项列出面积、惯性、质量和刚度贡献。等效后检查：

- 总面积；
- 形心位置；
- 主轴方向；
- 弯曲、扭转和剪切刚度；
- 线质量；
- 对目标响应最敏感的属性。

## 4. 建立质量 ledger

每一项质量只允许一个归属：

- 材料密度随几何自动生成；
- 非结构附件以节点、线或面质量加入；
- 旋转设备或偏心附件包含转动惯量和偏心；
- 施工人员与设备作为荷载或质量的选择由 charter 决定；
- 迎风面积单独登记，不能由质量替代。

按构件组、系统、阶段和来源汇总。

## 5. 独立属性校核

至少使用一种独立路径复算控制截面：

- 手工公式；
- 第二几何积分库；
- CAD region 属性；
- 材料表总重反算；
- 标准型钢表。

比较差异并使用 charter 阈值判断。

## 6. 分配属性

将 MAT-ID、SEC-ID 和 mass item 映射到 geometry object 和 componentGroupId。检查 orientation 与局部轴一致，截面变化站点与图纸一致。

# 质量门

G7 通过条件：

1. 所有需要刚度的对象有材料和截面；
2. 所有质量/荷载对象有唯一 ledger 归属；
3. 控制截面属性通过独立复算；
4. 总质量、分系统质量和材料表/工程量对账在阈值内；
5. 形心、主轴和 orientation 正确；
6. 阶段属性切换完整；
7. 等效属性有保留效应和验证目标；
8. 高敏感材料或截面参数已形成边界情景；
9. 无密度与附加自重重复计入。

# 失败处理

若截面细节不足，可按节点 06 的 representation contract 建立参数化截面。若截面参数范围导致关键刚度、质量或承载复核跨越验收限值，G7=`BLOCKED`。禁止用求解器默认截面参数填补空值。

# 完成检查

1. 材料参数是否带版本、温度、龄期和来源？
2. 截面属性是否包含所需剪切、扭转和翘曲参数？
3. 形心、剪心和局部轴是否明确？
4. 等效构件贡献是否逐项可追溯？
5. 质量与重力是否分开并防重复？
6. 是否完成总质量和分项对账？
7. 是否使用独立路径复算控制截面？
8. 是否处理阶段相关属性？
