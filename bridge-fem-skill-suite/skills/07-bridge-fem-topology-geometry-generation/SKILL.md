# 任务

你负责生成有限元几何与拓扑中间表示。输出必须保留设计几何、分析参考几何和两者之间的偏移关系，使节点 08 至 14 能在不重新解释图纸的条件下继续工作。

# 输入契约

- analysis charter；
- evidence graph、coordinate transform register；
- abstraction decisions 与 representation contract；
- dimension register；
- project tolerance policy；
- solver-neutral element capability model。

# 输出工件

- `fem_geometry_ir.json`；
- `topology_audit.json`；
- `geometry_overlay_report.json`；
- `coordinate_system_register.json`；
- `geometry_parameter_table.json`；
- `node_merge_log.json`；
- `geometry_issues.json`。

# 不可违反的规则

1. 设计几何与分析参考几何分开保存。
2. 所有坐标带 coordinateSystemId 和单位。
3. 节点合并只按项目容差和拓扑语义执行，禁止依赖求解器自动合并。
4. 交叉线若存在结构连接必须生成共享节点或连接对象；仅投影交叉时禁止误连。
5. 梁、索、壳的局部轴和 orientation 显式定义。
6. 偏心、刚臂和参考面 offset 不能通过移动几何后丢失物理来源。
7. 曲线离散误差要绑定 chord error、角度或响应敏感性。
8. 零长度、重复单元、悬空节点、自交面和负体积禁止进入下游。
9. 对称复制、阵列和镜像要保存生成规则和实例 ID。
10. 所有几何对象必须回溯到 componentGroupId、sourceRefs 和 abstraction decision。

# 工作顺序

## 1. 建立坐标系统

冻结全局桥轴坐标。为斜交桥、曲线桥、塔柱、索面、横梁、支座和局部节点建立局部坐标系。记录原点、轴向、右手性和父坐标系。

## 2. 生成参数骨架

按工程角色建立：

- 梁、桁架、索和杆件中心线；
- 壳中面和板件参考面；
- 实体分析域；
- 支承、锚固、连接和荷载作用点；
- 桥轴、里程、跨界和阶段控制点。

所有关键节点优先由标注尺寸、坐标和装配关系计算，避免从绘图线长度直接量取。

## 3. 处理偏心与参考位置

记录构件真实形心、剪心、连接面、中面和分析线之间的偏移。决定采用：

- 节点坐标偏移；
- element offset；
- 刚臂；
- MPC；
- 壳厚偏置；
- 独立连接节点。

选择必须遵循 abstraction contract，并保留偏心向量来源。

## 4. 拓扑连接

对每个连接位置判断：共节点、端部释放、MPC、刚臂、弹簧、接触或无连接。节点 07 只生成几何接口，具体刚度和自由度由节点 09 定义。

执行图论检查：连通分量、度数异常、孤立节点、意外闭环和路径断点。

## 5. 曲线和索线离散

- 曲梁按曲率、截面变化、荷载变化和目标响应分段；
- 索按初始曲线、垂度、集中连接和找形要求分段；
- 壳面按边界、开孔、加劲、支承和局部输出区分区；
- 实体域按接触、材料和应力梯度分区。

本节点生成几何分段，网格密度最终由节点 12 决定。

## 6. 节点合并

合并候选要同时满足：

- 空间距离小于 merge tolerance；
- 所属结构接口允许共节点；
- 坐标系和阶段兼容；
- 不存在间隙、滑移、接触或偏心要求。

每次合并记录 old IDs、new ID、距离和依据。禁止批量合并后丢失记录。

## 7. 几何不变量检查

至少检查：

- 跨径、总长、标高和关键间距；
- 截面站点和构件端点；
- 支座、锚固和索鞍坐标；
- 对称关系；
- 构件交点；
- 闭合轮廓和壳法向；
- 设计线形与分析线形差异。

## 8. 回投图纸

把 FEM 参考线、中面、节点和偏心矢量回投到对应视图。生成平面、立面、横断面和节点详图 overlay。对每个控制点输出偏差。

# 质量门

G6 通过条件：

1. 所有显式和等效构件有稳定几何接口；
2. 全局和局部坐标系闭合且右手性正确；
3. 关键尺寸、坐标和标高在项目容差内；
4. 无零长度、重复、孤立、误连、自交或负体积对象；
5. 偏心和 offset 全部显式；
6. 节点合并日志完整；
7. 传力路径在拓扑图中连续；
8. 回投 overlay 通过；
9. 高敏感几何参数以情景或参数表表达。

# 失败处理

若图纸只能确定端点而无法确定曲线中间线形，使用 abstraction decision 中批准的参数曲线或找形分支，并将几何状态标记为 `requiresInitialState=true`。若未知线形会改变连接位置、净空或验收结论，G6=`BLOCKED`。

# 完成检查

1. 是否分开保存设计几何和分析参考几何？
2. 是否显式记录坐标系、偏心和局部轴？
3. 是否区分真实连接与投影交叉？
4. 是否记录每次节点合并？
5. 是否检查拓扑连通和孤立对象？
6. 是否按曲率和结构断点分段？
7. 是否执行关键尺寸不变量检查？
8. 是否完成图纸回投？
