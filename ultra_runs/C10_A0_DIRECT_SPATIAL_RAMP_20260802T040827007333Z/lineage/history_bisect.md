# C10 静力端点历史二分审计

## 结论先行

1. 最后一次真正通过完整静力端点的运行是 `S10_SECTION_SHEAR_20260716T050342389124Z`。它包含 142 品有限刚度门架、21 道横向通道、17,679 个 BEAM188 物理梁和 33,003 个 MASS21，但连接是 5,078 条 `CERIG`，不是 MPC184。
2. 项目历史中没有任何一个同时含“有限门架/通道 + MPC184 + MASS21”的全桥 run 通过完整静力端点。微算例通过不等于全桥静力通过。
3. S10 与 C10 的节点、物理梁、MASS21、材料/截面、死载源、重力和 LINK180 初始状态均字节级不变。首个未被历史成功运行覆盖的物理改变，是将 5,078 条 CERIG 替换为 5,078 个 direct-elimination MPC184 rigid beam。
4. 当前 C10 在 `beta=1`、即二期恒载保持在旧 MCT 平衡位置时，LS1 只用 4 次迭代就收敛；一旦开始向最终 MASS21 空间位置迁移，即使单次只迁移 `5E-7`，也需 29/45 次迭代。因此最小故障边界是“MPC184 非线性连接运动学 × 空间质量荷载穿过门架刚性接口”，而不是全局秩奇异、质量总量错误或 KEYOPT(5) 几何刚度开关。
5. `PRED,OFF` 不是后来引入的回归：S10 成功线与所有当前迁移线都明确使用 `PRED,OFF`。它可能是平滑 ramp 的性能放大器，但不是历史二分得到的物理根因。

## 当前失败与历史差异的交叉证据

- 当前运行始终为 1,234,834 个方程，最小主元为正值 25.3126539，没有 small/zero/negative pivot、刚体运动或硬事件。这不支持“全局秩失败”说法。
- `C10_MICRO_VALIDATION_20260801T190634755506Z` 的单层 TYPE72 微算例 12/12 通过，说明单连接代数与基本六向传力没有简单错误；它不能覆盖全桥的偏心、大转角和刚性环交互。
- `TYPE72 KEYOPT(5)=0→1` 的历史单变量运行仍在首个 0.5% 迁移增量发散，因此排除“只要关闭 MPC184 stress stiffness 即可修复”。
- 当前受控运行的两个 LS2 接受步均为 `5E-7`，后一步 45 次迭代、每最小步实测 2,872.3 s，剩余路径投影 66.422 天；这是数值上可偶尔接受、但工程上不可运行的路径。
- `qa/nrre_residual_audit.md` 的前 9 个完整 NRRE 帧中，每次迭代的节点力 Top50 都是 `TYPE72 + ALL + 迁移节点`；尖峰对称集中在 H01/H03，并扩展到 H02/H16/H17 等刚性接口。节点力峰值约 `7.684E5 N`，节点力矩峰值约 `9.881E6 N·mm`。该证据直接把问题局部化到荷载迁移经过的门架 ALL 刚性对，但仍不能在没有图纸自由度证据时直接宣布某条连接应释放。

## `PRED` 单变量判定

- S10 成功主输入第 189 行是 `PRED,OFF`。
- 当前迁移主输入第 227 行也是 `PRED,OFF`；早期 `0132_directlink`、`0221_penalty5e10` 及其重启路径同样是 `OFF`。
- `0111_mpc184` 没有显式 PRED，即使用 MAPDL 默认 `AUTO`，但它因罚刚度 joint 滑移在首子步终止，不能用于证明 predictor 有效。
- ANSYS 官方 `PRED` 说明指出：默认是 `AUTO`；平滑的 ramp 非线性路径可从线性 predictor 受益；存在转动自由度时 quadratic predictor 可能更高效，但大转角也可能要求更小子步。参见：<https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/ans_cmd/Hlp_C_PRED.html>。

因此 PRED 应只作为数值效率 A/B：在同一接受帧、同一增量、同一准则下比较 `OFF` 与 `AUTO/LINEAR`；有两个已接受的同载荷步历史后再试 `QUADRATIC`。验收必须同时比较迭代数、切步、残差峰值、端点反力和路径一致性；不得以“迭代变少”代替连接物理复核。

## 建议的最小 A/B 修复路径

### A0：先做真正的“连接唯一差异”全桥静力测试

在新 run/jobname 中使用当前 5,078 个 TYPE72，但完全恢复 S10 已成功的静力路径：MASS21 include 清除旧 FZ 后，从零直接将最终空间重力以 `KBC,0; AUTOTS,ON; NSUBST,20,200,20; PRED,OFF` ramp 到终点，然后只做一个 LS2 无变化保持步。截断在静力，不跑模态。

这是优先级最高的二分，因为历史 S10 已经是它的 CERIG 对照，不需要重跑对照组。

- 若 A0 通过：说明 TYPE72 终点可解，当前 `beta=1→0` 迁移 homotopy 才是不必要且病态的路径。应退役迁移路径，保留直接 ramp，再做反力/能量/残差闭环。
- 若 A0 仍失败：就将问题压缩为 CERIG→MPC184 的全桥非线性运动学变更，不再继续花 66 天试更小迁移步。

A0 的强制门禁：固定软件版本与 SMP1；不同时改 PRED/CNVTOL/KEYOPT；每子步记录迭代数和 NRRE；校核全局力与力矩、门架子结构自由体、质量、反力和终点线形。

### A0 与“分组件迁移”的排序

两者回答的问题不同，不应并行盲跑：

1. **A0 是最短验证**：它不声称重现施工顺序，只用历史已成功的直接空间重力 ramp，以最少新假定判定“当前 TYPE72 终点是否可达”。它不需要设计新的组件分组、中间平衡状态或阶段锁定，因此是当前最快的因果门。
2. **分组件迁移是定位/修复路径**：它应在 A0 失败后使用，按门架、横通道、索上保留质量等物理组件家族一次只迁移一组，从而确定首个产生 NRRE 尖峰的组件/接口。每组都必须单独守恒总力与总力矩，并在下一组激活前通过局部自由体平衡。
3. **A0 通过时**：先把直接 ramp 作为“静力终点候选路径”完成残差、反力、能量、步长敏感性和独立复核；若分析用途只需最终预应力基态，分组件迁移可降为敏感性对照。若用途要求重现实际安装/转换顺序，即使 A0 通过，仍必须另行建立有工程依据的分组件阶段，A0 不能代替施工阶段模型。
4. **A0 失败时**：不再以更小的全量迁移步长硬耗；立即转入分组件迁移，优先 H01/H03 及其对称对照，并把首个失稳组件交给 A1 的局部连接自由度 A/B。

因此总排序是：**A0 短验证 → 若失败则分组件迁移定位 → A1 热点连接物理修复 → A2 PRED 纯性能优化**。任何一步都不允许直接进入模态，必须先取得可验证的静力端点。

### A1：若 A0 失败，只修热点连接，不全量回退

以 H01/H03 为第一局部包，并将 H02/H16/H17 作为复核包；只对 NRRE 持续热点的 ALL 刚性对做两种连接小模型/局部全桥 A/B：

- A：当前 TYPE72 六自由度 direct-elimination rigid beam。
- B：诊断用 CERIG 还原，或依连接详图定义的平动传递 + 明确转动释放/有限刚度。

只有图纸或已批准假定能决定 B 是哪一种物理语义。CERIG 回退只是因果诊断，不是默认生产方案。验收指标是残差尖峰、迭代数、局部相对转角、接口力/力矩和全桥终点差，不是“能跑完”一项。

### A2：在物理路径通过后再做 PRED 性能 A/B

保持模型、负载、初始状态、步长、CNVTOL 和并行模式全部相同，只比较：

1. `PRED,OFF`（历史基线）；
2. `PRED,AUTO`，或强制 `LINEAR`；
3. 至少已有两个平滑已接受子步后，再试 `PRED,QUADRATIC`。

若 predictor 仅降低迭代数而不改变路径与端点，可作为性能配置；若出现过预测、额外切步或热点放大，就恢复 `OFF/AUTO`。
