# 首轮输出拒绝说明

首轮只读 MAPDL 执行完成且源 DB/RSTP 安全，但在线 QA 发现 `a10_sene6_modal_numeric.csv` 为 1680 行，而目标为 80 阶 × 6 组件 = 480 行。

原因是 APDL `*VWRITE` 接收 `E_COMP(I_COMP)` 与 `R_COMP(I_COMP)` 数组项后，会从当前索引继续向数组末尾自动展开。每阶六次写调用因此分别产生 6、5、4、3、2、1 行，合计 21 行；80 阶最终得到 1680 行。数值读取本身无误，但行结构不符合交付契约，所以整轮输出拒绝，不用于最终 QA。

正式输入已改为先把数组项赋给标量 `E_CURRENT` 与 `R_CURRENT`，再执行 `*VWRITE`。本目录保留首轮 CSV、OUT、ERR 和 LOG 作为拒绝证据，正式结果位于上一级目录。
