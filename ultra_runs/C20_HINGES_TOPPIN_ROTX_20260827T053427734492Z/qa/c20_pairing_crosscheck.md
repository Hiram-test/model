# C20 表4-1配对独立交叉复查

日期：2026-08-27。单位 N, mm, tonne, s。
本文件**不调用** `_pair_modes_table41.py`。证据链：S10 官方 PFACT/EFFM、五站位测点符号、门架 toppost SENE vs 索位移、测点向量余弦。

## 方法

1. **S10 旁证**：S10 `s10_modal_properties.csv` 的 `*GET MODE,PFACT/EFFM` 是官方值。C20 与 S10 同阶频率差 ≤ 5e-5 Hz 时，把 S10 方向有效质量当作 C20 该阶的旁证（C20 本 run 的 MODE `*GET` 在 RESUME eq.db 后为 0）。
2. **符号模式**：五个 X 站位（边跨北、Q1、跨中、Q3、边跨南）× 两幅猫道（Y+、Y−）。只用 Q1/跨中/Q3 六个测点（边跨站 node 80/29176 对主跨模态接近 0，不参与主跨对称判定）。
   - 两幅 UY 同号 = 横弯同相；两幅 UZ 反号 = 扭转；Q1 与 Q3 反号 = 顺桥反对称。
3. **全桥 vs 门架局部**：主跨测点 RMS < 1e-6 **且** GATE_TOPPOST SENE≥0.50 **且** TYPE4 SENE<0.08 → 门架 ROTX 局部。仅凭 `rs`（六组 CM 合计，含横通道）≥0.80 **不能**判局部。
4. **MAC 思路**：六测点 (UY,UZ) 12 维向量余弦，检查杂交对是否几乎共线。

判定：

- M3/M4 主跨索测点位移与 LS1（~3e-2）同量级，**不是**死索。
- M3/M4 的 GATE_TOPPOST 只占 2%/10%，84% 的 `rs` 主要来自 **TYPE70 横通道+门架框**，不是立柱顶局部弯曲。
- 单点 `GATE_TOPPOST_NODE=2000040` 在 M3/M4 上位移 ~1e-16，该节点不代表整组门架能量。
- M27 起 toppost SENE≈0.85、TYPE4≈0.02、主跨测点 RMS 比 M3 小两个数量级以上，才是门架 ROTX 局部簇。
- **结论：M3、M4 是全桥主跨反对称杂交模态（横弯+扭转），不是门架局部模态。**

M3 vs M4：

- M3 shareL=0.509 shareT=0.484，UY 两幅同相、UZ 两幅反相、Q1/Q3 反号 → 反对称扭转与反对称横弯几乎各半。
- M4 shareL=0.550 shareT=0.443，同一套符号，横弯份额略高。
- S10 M3/M4 的 EY、EZ 都 ~1e-8 以下，ERX 同为 4.2e5 量级：平移有效质量被反对称抵消，旋转有效质量大，**不能**靠 EY 把一阶标成横弯、另一阶标成扭转。
- 原配对把 M3→TA1、M4→LA1 是份额上的弱排序，不是两个干净的物理阶。**杂交事实成立；LA1/TA1 谁对应哪一阶只有中等置信。**
