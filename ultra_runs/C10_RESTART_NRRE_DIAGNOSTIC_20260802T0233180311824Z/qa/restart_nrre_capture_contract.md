# 复制重启残差采集合同

- 精确重启点：`R002 = load step 2 / accepted substep 2`，由同版本 MAPDL `RESCONTROL,FILE_SUMMARY` 原生输出确认。
- 重启前累计迭代：`93`，来自来源运行最终 MNTR；下一子步原运行在第 `42` 次迭代由有效 ABT 中止。
- 唯一诊断改动：启用 `NLDIAG,NRRE,ON,50`，并把下一子步限制为 `NEQIT,12`、累计迭代上限 `105`。
- 预期终态：由 MAPDL 自身按诊断迭代上限结束，保留 `Jobname.nrxxx`；不使用外部 terminate、kill 或进程信号。
- 残差文件只用于定位局部连接、索活动状态或荷载位置问题，不得用于模态、设计、静力终态或生产结果。
- 运行后必须确认来源四个复制重启文件在准备时摘要闭合；重启可能按 MAPDL 合同更新新目录内的 LDHI/Rnnn，因此不得把运行后变化误判为来源运行漂移。
