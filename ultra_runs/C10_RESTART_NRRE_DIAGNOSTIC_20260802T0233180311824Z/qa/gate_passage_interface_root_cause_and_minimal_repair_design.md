# C10 门架—横通道接口根因审计与最小修复设计

审计时间：2026-08-02。本文只使用冻结输入、质量/荷载账本以及当前重启动诊断已经写完的 `nr001`～`nr006`；不写入、不停止、也不改变正在运行的 ANSYS 作业。本文是诊断与修复设计，不是结构连接签认，也不把未收敛 NRRE 帧当成工程结果。

## 1. 先给判定

| 假设 | 当前判定 | 置信度 | 依据与边界 |
|---|---|---:|---|
| 横通道接口的 `ALL` 六自由度语义本身错误 | **未证实，禁止直接修改** | 中 | 生成器明确把它定义为“含刚体转动”，但 5,078 条连接都没有逐条图纸编号；NRRE 热点不能替代焊缝、螺栓、节点板或支承构造源证。 |
| 同一门架下横梁与两条横通道顶弦之间的过密刚臂造成严格代数冗余/失秩 | **严格失秩已被现有证据否定；高条件尺度与强闭环放大仍成立** | 高 | 1,386 个横通道 `ALL` slave 全部唯一，无重复主从对；运行方程数恒为 1,234,834，最小报告主元为正值 25.3126539，未出现 small/zero/negative pivot。但每道横通道形成 64 点分布式六自由度复合连接，至少形成 60 个“有限梁—刚臂—有限梁”闭合单元，具备强约束放大条件。 |
| 荷载迁移把质量或重力在刚接主从两侧重复计入 | **重复计重被质量账否定；两侧同时承载不同物理构件质量为真** | 高 | 二期质量空间化前后均为 963.811380787273 t，误差约 `1.14E-13 t`；门架质量、横通道质量属于不同组件。主、从节点都带 MASS21，但不是同一质量复制两次。 |
| 恒总荷载位置迁移是当前慢收敛的触发器 | **已证实** | 很高 | `beta=1` 的旧 MCT 荷载位置在同一连接拓扑上 4 次迭代收敛；唯一改变为 `beta` 下降后，首两个 `0.05%` 最小迁移子步分别需要 29、45 次迭代。 |
| 64 点 `ALL` 接口是触发后的主要残差放大/凝聚位置 | **已证实为位置，因果贡献仍需 A/B 定量** | 高 | `nr002` 的 8.535 MN 全局力残差在 H01/H02/H03 对称的门架下横梁—横通道顶弦主从节点上形成 0.57～0.76 MN 局部峰值和 8.1～9.9 MN·mm 主节点弯矩峰值。 |

当前最合理的工程因果链不是“三选一”，而是：

> **同步荷载位置迁移是触发器；分布式六自由度刚接闭环和 direct-elimination 的残差凝聚是放大器；`ALL` 的真实物理语义仍缺连接详图，不能靠数值热点擅自改成铰接。**

因此第一修复应保持 5,078 条连接、质量总量和最终 `beta=0` 荷载向量不变，把一次同步迁移改为按物理组件/装配分组的零总力顺序迁移。只有 A/B 证明连接语义本身错误且图纸给出释放依据后，才允许改连接自由度。

## 3. 接口拓扑复原

### 3.1 `ALL` 热点不是立柱焊缝

`builder/build_finite_gate_passage_apdl.py:1911-1958` 定义的四个立柱端部连接确实是 `ALL` 焊接偏置，但当前 H01～H03 热点不属于这些连接。

热点连接来自 `builder/build_finite_gate_passage_apdl.py:2162-2193`：每道横通道、每幅猫道、16 根底索位置、前后两条顶弦各建一条 `ALL` 刚臂。对应冻结映射例如：

|---|---:|---:|---|
| `C10-CONN-03711` | 2000140 | 2009264 | H01 / CW1_GATE_03 / rope10 / 顶弦 `r=0` |
| `C10-CONN-03737` | 2004681 | 2009290 | H01 / CW2_GATE_03 / rope07 / 顶弦 `r=0` |
| `C10-CONN-03777` | 2000332 | 2010242 | H02 / CW1_GATE_06 / rope10 / 顶弦 `r=0` |
| `C10-CONN-03803` | 2004873 | 2010268 | H02 / CW2_GATE_06 / rope07 / 顶弦 `r=0` |
| `C10-CONN-03843` | 2000524 | 2011220 | H03 / CW1_GATE_09 / rope10 / 顶弦 `r=0` |
| `C10-CONN-03869` | 2005065 | 2011246 | H03 / CW2_GATE_09 / rope07 / 顶弦 `r=0` |

每个上述 master 还连接同一位置的 `r=1500` 第二条顶弦；例如 2000524 同时通过 `C10-CONN-03844` 连接 2011221，2005065 同时通过 `C10-CONN-03870` 连接 2011247。

### 3.2 分布式复合闭环的数量

- 横通道 `ALL` 逻辑连接：1,386 条。
- 每道横通道：66 条，其中 64 条是两幅猫道 × 16 个横向位置 × 两条顶弦，另 2 条是端部三角接口根节点。
- 唯一 master：672 个；唯一 slave：1,386 个；master/slave 交集为 0；每个 slave 只出现一次，因此没有重复 MPC 方程对。
- 每幅猫道的门架下横梁 master 之间有连续 BEAM188；两条横通道顶弦 slave 之间也分别有连续 BEAM188。相邻 16 个位置形成每条顶弦 15 个“门架梁—刚臂—顶弦梁—刚臂”闭合单元。
- 每道横通道至少形成 `2 幅 × 2 条顶弦 × 15 = 60` 个这种闭合单元；21 道合计至少 1,260 个。它们不是重复代数约束，因为闭合边之一是有限刚度梁；但它们会把两个独立有限梁系统组成强复合带，并把弯矩和转角兼容集中到直接消元节点。

热点固定出现在 CW1 rope10 与 CW2 rope07 的对称位置，恰位于 1,700 mm 大分段间距的内侧边缘；普通相邻底索间距约 260 mm。该重复空间签名支持“复合接口的刚度突变/凝聚”解释，不支持“随机质量节点错误”解释。

### 3.3 为什么目前不能叫作严格失秩

- 5,078 个 TYPE72 在全部观测组装中方程数恒为 1,234,834。
- 最小报告主元 25.3126539，且没有 small、zero 或 negative pivot。
- 12 个单连接微算例全部通过，但这些微算例没有覆盖“门架梁 + 两条连续顶弦 + 64 个刚臂”的闭合网络，因此只能证明单个 MPC184 的运动学，不能证明分布式接口的条件尺度。
- 求解输出已报告单元最大矩阵系数范围 `3.846764609E11` 至 `2.677552402E-09` 并给出 `Coefficient ratio exceeds 1.0e8`。最小值所在单元 2022030 是 H10 的 `ALL` 横通道三角接口根节点刚臂。这是条件尺度警告，不等同于零主元。
- ANSYS 对 direct-elimination MPC184 的 spiderweb 明确要求共同节点必须为 independent node。当前冻结输入把共同门架节点固定写为每条 `EN` 的 I 端，满足现有生成意图；仍应在执行期元素清单中逐条复核，不能只依赖注释。官方说明：[MPC184 Link/Beam](https://ansyshelp.ansys.com/public/views/secured/corp/v251/en/ans_elem/Hlp_E_MPC184link.html)。

所以应使用“高条件尺度的强闭环接口”而不是“已经证明的运动学冗余/秩亏”。

### 4.3 当前一次迁移实际同步改变了什么

- 11,947 个正修正节点恰好是全部生成物理节点：门架 4,828 个、横通道 7,119 个。
- 3,124 个负修正节点恰好是全部旧 UXYZ 索 slave。
- 门架质量：323.191107485208 t，对应 3,169,212 N 重力。
- 横通道质量：212.826840709770 t，对应 2,086,980 N 重力。
- 合计迁移：536.017948194978 t、5,256,192 N；占二期空间化质量约 55.61%。
- 单个 `0.05%` 最小迁移子步只移动约 2,628.096 N 的载荷位置，但 `nr002` 的全局力残差达到 8.535 MN，放大超过三千倍。这证明它不是未平衡外力大小本身，而是 Newton 更新、几何刚度与接口凝聚的相互作用。
- 全修正向量和为约 `2.09E-10 N`，总竖向荷载守恒；因此“总荷载跳变”不是现有证据支持的根因。

## 6. 最小 A/B 诊断顺序

所有 A/B 都必须创建新目录、新 jobname，并从源重启动帧复制后校验哈希；不得改当前 restart run。每组只允许一个差异，保持 `CNVTOL`、`NLGEOM`、初始状态、总质量、最终荷载向量和无硬停合同不变。

### A/B-0：冻结当前基线

当前 restart 的一个 `5E-7` 伪时间增量加 `NLDIAG,NRRE` 就是 A0。等待 ANSYS 按 `NEQIT/NCNV` 原生结束，汇总全部 NRRE 的 top 节点、连接 ID、装配、奇偶迭代和残差范数。A0 不做任何修复，只提供可重复比较基线。

### A/B-1：零总力物理分区，确认触发分量

现有 15,071 条有效修正全部属于“旧 UXYZ 索节点 → 新门架/横通道节点”的 536.018 t 位置迁移，并不存在可供对比的非门架/非横通道有效分区。应从质量组件分配台账重建若干**各自严格零总力**的修正子向量；每个子向量必须同时包含旧位置负力和新位置正力，禁止只冻结正侧或只冻结负侧。

- A1：只推进门架组件分区一个与 A0 相同的归一化迁移量，包括 `gate_bottom_beam`、`ordinary_gate`、`guide_roller` 和按台账归入 gate 的 dedicated 三角门架质量；横通道半幅分区保持当前 beta。
- B1：只推进 `cross_passage_half` 横通道分区，全部 gate 组件保持当前 beta。
- C1：只推进 H03 对应横通道及其 dedicated gate 的完整配对分区，其他 20 道横通道和普通门架保持当前 beta。
- 每个分区写出节点数、`ΣFz`、关于全局原点的 `ΣMx/ΣMy`、来源组件和最终与原完整修正向量重组误差；`|ΣFz|` 必须小于 `1E-6 N`。

预期签名：若 B1 显著强于 A1 地重现 H01～H03 的 master/slave 峰值，横通道自重迁入是主触发分量；若 A1 更强，门架荷载通过 UXYZ/ALL 双层接口的转送是主触发分量；若 C1 只在 H03 产生同构热点而其他 H 点不出现，装配级顺序迁移具备直接修复依据。若 A1/B1 都在未推进的装配上产生同等级全局峰值，则应把调查扩展到全局索初态/切线，而不是改局部连接。

### A/B-2：分装配顺序迁移，作为首选最小修复

保持所有连接和全部 MASS21 不变，把原来 536.018 t 同步迁移改为装配级顺序迁移：

1. 每道横通道 H01～H21 连同其配对旧节点负修正形成独立零总力组；先用 H03 做单组测试。
2. dedicated gate 与普通 gate 按完整物理组件形成组，禁止按“正节点/负节点”机械切分。
3. 每组内部采用自适应小步，但不同组不同时改变；优先测试从跨中向两端与从两端向跨中两种顺序。
4. 所有组完成后，最终 15,071 节点的 FZ 必须逐节点等于原 `beta=0` 端点；最终 MASS21、连接、材料、截面完全不变。

判定门：相对 A0，单组测试的中位迭代数至少降低 5 倍，或峰值 CNVV 至少降低 10 倍；任何 small/zero/negative pivot、方程数漂移、LINK180 非正轴力或新热点转移均判失败。最终还要用两种组顺序独立到达 beta=0，检查位移、索力、反力、能量和刚臂几何在预先冻结容限内一致。路径一致性未通过时不得把顺序迁移升格为正式基态。

### A/B-3：只凝聚刚臂 slave 上的静力重力增量

若 A/B-2 仍慢，保持 1,386 条 `ALL` 和其他质量不变，只对位于 direct-elimination slave 上的 14.4800530389247 t MASS21 做静力等效 A/B：

- A3：重力增量照常作用在 slave。
- B3：在该微增量内以反向节点力抵消 slave 的增量重力，并在相应 master 施加等效 `F` 与 `r×F`；`r` 取接受构形下的当前 master→slave 向量。
- B3 必须逐刚臂闭合力和力矩，且仅用于一个极小增量的数值诊断。

预期签名：若 B3 显著改善而 A3 不改善，同时两者的线性化响应、反力和能量一致，则 direct-elimination 的受约束节点载荷凝聚是主要数值机制。正式静力可考虑把受约束节点重力等效到 independent DOF；但模态质量必须做完整一致质量/惯量凝聚，禁止简单删除或搬移 MASS21 后直接做模态。

### A/B-4：保持六自由度语义，改变约束实施法

只有 A/B-1～3 不能解释时，才允许从全新 LS1 做一组“全部 5,078 个 TYPE72 从 direct elimination 改为 Lagrange multiplier”的单差异诊断。ANSYS 对 rigid beam 的 `KEYOPT(2)=1` 给出 Lagrange multiplier 实施法；但官方同时明确禁止把 direct-elimination 与 Lagrange multiplier 刚臂相互连接，因此**绝不允许只把 1,386 条 passage interface 改成 Lagrange 而让同一 master 上的 UXYZ 刚臂仍为 direct elimination**。官方说明：[MPC184](https://ansyshelp.ansys.com/public/Views/Secured/corp/v251/en/ans_elem/Hlp_E_MPC184.html)、[MPC184 Link/Beam](https://ansyshelp.ansys.com/public/views/secured/corp/v251/en/ans_elem/Hlp_E_MPC184link.html)。

该 A/B 会改变方程规模和矩阵类型，不能复用现有 restart，也不能直接作为生产修复；它只回答“同一六自由度物理约束下，direct elimination 是否为主要数值放大器”。

### A/B-5：物理连接自由度敏感性

只有取得横通道顶弦—门架下横梁的实际焊接/螺栓/支承详图后才执行：

- 按图纸逐接口定义 UX/UY/UZ/RX/RY/RZ，不得统一把 `ALL` 改为 `UXYZ`。
- 若图纸表明仅若干离散连接点传力，删除的连接必须按真实连接位置，不得采用“每隔一个删除”或“只留最外点”的数值试错。
- 新旧模型需做单位平动、单位转动、局部自由体、静力端点和预应力模态敏感性比较。

在图纸到位前，A/B-5 状态为 `BLOCKED_BY_CONNECTION_DETAIL`，不是当前可执行修复。

## 7. 建议立即实施的最小修复

建议把 **A/B-2 的“按物理组件/装配分组、每组零总力、最终逐节点完全回到原 beta=0”** 作为第一修复候选，原因是：

- 不改变 `ALL`/`UXYZ` 物理语义。
- 不改变总质量、重心、最终荷载位置或材料/截面。
- 直接针对已证实的同步迁移触发器。
- 可以从单个 H03 小试开始，失败成本远低于重跑全桥 2,000 个最小子步。
- 若两种迁移顺序到达同一 beta=0 端点并得到一致响应，可证明修复只是平衡求解路径，不是偷偷改变结构。

正式工具至少要输出：

1. `correction_partition_ledger.csv`：每条原/新节点力的组件、装配、组号、符号、值和来源行。
2. `correction_partition_audit.json`：每组及全组的节点数、力和、矩和、重组误差、原 include 哈希和新 include 哈希。
3. `migration_stage_plan.json`：组顺序、每组 beta、步长、接受准则和重启动写出点。
4. 每阶段 MNTR/OUT/NRRE 原件及哈希；禁止只保留汇总。
5. 两种组顺序的 beta=0 端点对比包；在该包通过前，`modal_requested=false`、`production_claim_allowed=false`。

若 A/B-2 不能把迭代数降到可接受范围，下一优先级是 A/B-3 的受约束 slave 静力载荷凝聚；不是释放转角。

## 8. 明确禁止项

1. 禁止因 H01～H03 热点就把全部 1,386 条 passage-interface `ALL` 改为 `UXYZ`、铰接或删除。
2. 禁止“每隔一个删刚臂”、只留外端、只留热点以外连接等没有图纸依据的拓扑调参。
3. 禁止把 master 或 slave 的 MASS21 删除、改密度、改总质量来换取收敛；当前账本没有重复计重证据。
4. 禁止只冻结正修正节点或只冻结 3,124 个负修正节点；任何迁移分组都必须自身零总力。
5. 禁止放宽 `CNVTOL`、提高 `NEQIT` 后把“最终算完”称为模型修复。
6. 禁止加弱弹簧、数值稳定化、质量缩放或人工阻尼后直接进入模态。
7. 禁止在相连刚臂上混用 direct-elimination 和 Lagrange multiplier MPC184。
8. 禁止用未收敛的 NRRE debug 帧做位移、内力、索力或规范结论。
9. 禁止改写、覆盖、续写当前正在运行的 restart 诊断目录或其 jobname。
10. 禁止把当前 builder 源码当作冻结 run 的逐字节重生器；任何物理重建必须先恢复缺失源、冻结命令行和哈希。

## 9. 本审计对修复决策的质量门

- `GO-A/B-2`：现有证据已经足够，允许准备新目录中的只诊断分组迁移输入。
- `NO-GO-CONNECTION-CHANGE`：没有逐接口图纸来源，禁止修改 `ALL` 自由度或连接位置。
- `NO-GO-PRODUCTION`：当前全桥只完成极小部分迁移，且 NRRE 仍是未收敛迭代证据。
- `ESCALATE-INITIAL-STATE`：若 A/B-1 只推进一个物理分区时，未推进的远端装配仍同步重现同等级全局峰值，或不同分组顺序到达不同 beta=0 平衡，则应停止局部接口修复，转入“最终空间质量位置下的索力/线形重新找平衡”工作流。

最终工程判断：**目前最小、可逆、证据充分的修复对象是荷载迁移路径，不是焊接连接。64 点 ALL 网络需要继续作为重点敏感界面审计，但在连接详图到位前只能保留并测试，不能擅改。**
