# TA1 偏低 26% 的根因（D10 计算证据）

日期：2026-08-27。单位 Hz；坐标 X 顺桥、Y 横桥、Z 竖向。

## 计算事实

| 量 | 值 |
|---|---|
| 实测 TA1（表4-1） | 0.0996 |
| C20 物理 TA1（M3 杂交） | 0.073357 |
| D10 Lanczos M3 | 0.073369 |
| D10−C20 M3 | +1.2e-5 |
| 纯张力反对称根 2f\*（LS1×2） | 0.07365 |
| D10 前 25 阶相对 C20 最大 \|Δf\| | 3.5e-5（第 25 阶） |

32 根 LINK180 总 EA、INISTATE 轴力与 C20 的 4 根等效索相同，只是按耳板散开并去掉 12 组塔处 CP。整体特征值不变，**下压索离散方式不是 TA1 的开关**。

C20 交叉复查：M3/M4 是全桥反对称 LA–TA 杂交，不是门架局部。GATE_TOPPOST SENE 仅 2%/10%，84% 的 `rs` 在横通道+门架框 TYPE70。

## 排除

1. 门架上销 ROTX（C20）：TA1 仍钉在 2f\*。
2. 下压 32 索替代 4 等效+CP（D10）：Δf ~ 1e-5 Hz。
3. 配对标错阶次：独立符号法 + S10 ERX 旁证确认杂交对，M6 才是第一阶扭转主导且为正对称 TS1。
4. 补 MASS21 转动惯量：只会降频，不能把 0.073 抬到 0.100。

## 根因

反对称扭转要的是两幅猫道竖向反相时，横通道四端口能以**相对转动/差动**提供抗扭 κ。当前 1386 条横通道 CERIG `ALL` 把四端口焊成刚臂，差动被锁死，有效抗扭仍约等于索张力几何刚度，所以 FEM TA1 ≈ 2f\* ≈ 0.0734 Hz，比实测低 26%。

M3/M4 的横通道 SENE 占 69–75%，说明能量已经堆在被刚臂锁住的 TYPE70 上，而不是以四端口软模态做功。
